# VISION
GENRE: 響 (Hibiki) — 触れた場所が「音」と「光の波紋」になる、水面のような波の楽器（インタラクティブ・アンビエント楽器）

## コンセプト
画面全体が、暗く深い水面（または光る膜）になっている。指やカーソルで触れると、その場所から本物の波動方程式にもとづく波紋が広がり、
波同士が干渉し、縁で反射し、光の屈折として美しく描かれる。同時に、触れた位置が音階上の音（横=音高、縦=音色の明るさ）になり、
残響を伴って鳴る。誰でも間違えようがなく「綺麗で気持ちいい」音楽が作れる、手のひらサイズの瞑想的な楽器。
新しさ: 音楽ゲームでも描画ツールでもなく、「波の物理」「音」「光」が1つの面で結びついた体験そのものがプロダクトであること。
長く育てる軸: 世界観（水・墨・絹・砂 など媒質の違い）、ムード（音階・色・残響）、演奏の記録とループ、マイク/傾きなどの入力、作品の保存と書き出し。
カメラ・マイク・センサーが無くても、デモモード（`?demo=1`、または入力取得失敗時）で「自動演奏する幽霊の指」が主要体験を見せる。

## 絶対のルール
**UX を最優先し、見た目は Apple 製品のように洗練され、美しいこと。**
具体的には: 初見の人が説明文なしで、ページを開いてから3秒以内に最初の心地よい体験（1回のタップで光の波紋が広がり、対応する音が返る）に到達でき、
さらに全画面（デスクトップ幅・スマホ幅の両方）が Apple 製品水準の余白・タイポグラフィ・階層・動き・アイコンの質・一貫性で整っていること。
雑な見た目、UI の不統一、スマホ幅での崩れ・操作不能、説明が必要な UI は、機能が豊富でも違反とみなす。

## UI 言語
日本語（ワードマーク「響」のみ漢字1文字。ラベルは短い日本語。英語UIの混在は避ける）

## 評価の観点
- 初回表示のスクショ: 何をすればよいかが文字なしでも／ごく短い一言で分かるか。画面は空っぽでなく、すでに美しいか（余白・階層・配色）。
- タップ／ドラッグ後のスクショ: 波紋が滑らかで繊細に描かれているか（ジャギー・ちらつき・白飛びが無いか）。触れた場所から反応しているか。
- 音: `document.body.dataset.audio` などの状態表示、および Web Audio が起動していることの確認（ヘッドレスでは聞こえないため、状態・コードで確認）。
- UI クローム: 最小限で、ガラス質・角丸・タイポグラフィ・アイコンが一貫し、Apple 製品のように見えるか。操作できる要素は迷わず触れるか（タップ領域 44px 以上）。
- スマホ幅 (390×844): 崩れ・はみ出し・セーフエリア干渉が無く、親指で全操作が届くか。
- デモモード: `?demo=1` で幽霊の指が自動演奏し、静止画でも波紋が見えること。
- 常時: コンソールエラー無し、真っ白画面無し、60fps 近い滑らかさ（重すぎて固まらない）。
