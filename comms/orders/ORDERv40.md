# ORDER v40  (mode: innovation)
## 目的
砂の調整が収益逓減（c35–c39 で 8 点横ばい）に入ったため、砂以外の軸で「触れた後の体験」を一段引き上げる、他のアプリに無い機能案を3つ発想する。

## やること
1. `app/NOTES.md` と現状のスクショ（`shots/cycle-039/` の home / bloom / letter-play / vessel-full / mood-* ）を見て、現在の機能（波紋・音・石・砂・手紙・器・気分 凪/夜/暁）を把握する。
2. `comms/IDEAS.md` の**末尾に「## Cycle 40 — 提案 (builder)」を追記**し、案 A/B/C の3つを書く。各案に: 名前 / 体験の一文 / 何が新しいか / 実装規模(S〜M) / 静止画2枚＋dataset での受け入れ条件 / VISION 自己チェック1行（説明文なし・3秒・Apple 水準の静けさ）。
   発想してほしい領域（3案は互いに別領域から）:
   - 領域1「音の深み」: 同じ場所をなぞる・重ねるほど音と光が成長する、演奏の質感（音色の変化、和音の積み重なり、減衰の物語）。現在の音は触れた1点ごとの単発で終わりがち。
   - 領域2「残すこと」: 演奏した水面を、静かな一枚の作品（画像/短い手紙）として持ち帰る・再訪できる体験。localStorage のみ、外部送信なし。既存の手紙/器との重複は避け、新しい価値を示すこと。
   - 領域3「媒質の違い」: 水以外の質感（墨・絹・光の膜 など）へ、バーを増やさず静かに移ろう仕組み。mood（凪/夜/暁）と直交する別軸として成立するか。
3. 砂は凍結（輝度・強度・形状のいずれも触らない案、砂を主役にする案は不可）。

## やらないこと
- app/ の変更、ビルド、スクショ撮影。バーへの要素追加を前提にする案。マイク・カメラ・傾き許可を初見で要求する案。ライブラリ追加を前提にする案。砂に関する案。

## 見た目・UX の要求
- 案は desktop・mobile(390×844) の両方で「静かで一貫」を保つ。説明文の増加・白飛び・ちらつきを招く案は不可。

## デモモード
全案が `?demo=1` の幽霊の指だけで評価できること。実機センサーや人間の操作が必要な案は不可。

## 作業役への注意
- 実装禁止（コミット対象は comms/ のみ）。
- 「面白そう」でなく、評価者が静止画と dataset で白黒つけられる案に絞る。規模は1サイクルで終わる S〜M。
- 既存機能の名前を羅列せず、現状の何が足りないかを1行で述べてから案を出すこと。
