# ORDER v93  (mode: normal)
## 目的
強い1打のあと約0.8秒で、同じ場所から小さな二次の輪と高い澄んだ一音が返る「跳ね返る雫」を入れ、初回1打の驚きを作る。

## やること
1. **跳ね返る雫（IDEAS c92 案A 縮小版）**。tap（離した時ではなく押下の瞬間）の強さが閾値以上のとき、800ms 後に同位置へ振幅 ≤0.35・幅 0.55 倍の波源を1回注入。音は1オクターブ上・音量 0.3・短い減衰で1本。
   - 発火条件: 強い打のみ／前回の発火から 2.5 秒以上／幽霊の連打（1 秒に 2 打以上）では発火しない／押下長押しの離し（press-rebound）では発火しない。
   - 受け入れ条件: `/?demo=1&seed=1&hour=13` の幽霊の最初の強い打から 1.3 秒後の desktop 画で、大きな青輪の内側に半径が約 4 割の小さな輪が 1〜2 本見え、「二重の輪」と読める。塗り円盤・泡にならない。`?rebound=0` で同じ撮影をすると内側の輪が無い。
   - `document.body.dataset.rebound = "回数,最後の振幅比"`（無効時 "off"）。
2. **press-rebound との区別**。既存の「押して離すと2つ目の輪」とは別物として共存させる。受け入れ条件: `desktop-press-rebound` が変化せず、同時に両方が出ても輪が3本以上重なって濁らない（短押し時のみ雫、長押し離しのときは雫を出さない）。
3. **shots.json**: `rebound-ring`（幽霊の1打の 1.3 秒後）と `rebound-off`（`rebound=0`）を desktop / mobile の独立画面で宣言。受け入れ条件: shots 一式でコンソールエラー 0、他画面は無変化。

## やらないこと
- 底の光の調整、新しい UI・文字・ボタン、案B・案C の実装、他機能の微調整、波速の変更。

## 見た目・UX の要求
- desktop(1280×800): 二次の輪は主の輪と同質の青い細い線。金・発光・強い白は使わない。
- mobile(390×844): 打点が下半分でも内側の輪が画面内で読める。輪の太さは主の輪より細い。
- 放置中のホームは現状と画素一致（静けさ不変）。1打目の即時反応（3秒以内に波紋と音）は不変。

## デモモード
`/?demo=1&seed=1&hour=13`（既定で有効）と `&rebound=0`（対照）。probe 例: `[{"goto":"/?demo=1&seed=1&hour=13"},{"wait":2300},{"shot":"rb"},{"eval":"document.body.dataset.rebound"}]`。

## 作業役への注意
- 二次の輪が「二重打ちのバグ」や泡に見えたら、振幅を上げず小さく・細くする。それでも読めなければ撤退し、REPORT に正直に書く。
- 音は聞こえないので、dataset と OfflineAudioContext のピーク比で確認する。
- NOTES.md に機構（発火条件・定数）を追記。コンソールエラー 0 を必ず確認。
