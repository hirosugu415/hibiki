# ORDER v18  (mode: normal)

## 目的
砂州の見え方・折れ・スマホ端の 3 つの粗を直し、さらに**演奏が URL に宿って人に渡せる**「響の手紙」の最小版を、UI を足さずに加える。

## 現状（司令塔 v17: 7/10、コミット済み `7103c0e`、ヘルス OK）
石（反射・回折）＋砂州（屈折・潮・鐘）で「触れて返ってくる量」は増えた。残る粗: ① desktop で砂州がほぼ見えない、② 砂州境界で輪が直線的に折れる（`mobile-touched.png` 左上）、③ スマホで砂州が右端にかかる。7 点は 8 サイクル横ばいなので、演奏の「持ち帰り」という新しい軸を最小で足す（IDEAS v16 案B）。

## やること（優先順）
1. **砂州の磨き（3 点まとめて）**
   - (a) 屈折の折れ対策: 境界の smoothstep 幅を約 16 → 28〜36 セルへ広げる（`uK` の最低値 0.30 は据え置き、**下げない**。実効 0.47 未満を維持）。
   - (b) desktop での可視性: 明るさのうねりを現状の約 1.5〜2 倍にする。ただし縁・輪郭線・塗り円盤は禁止。ムード（凪・夜・暁）すべてで汚れ／泡に見えないこと。
   - (c) スマホ幅（短辺が小さい画面）で、砂州の潮の x 範囲を「砂州の右端が画面内に収まる」ように狭める（例: x 中心 = 0.5 + (0.5 − rx/幅 − 0.06)·sin。desktop では従来とほぼ同じ範囲）。`dataset.bar` は従来どおり。
   - 受け入れ条件: `desktop-idle.png` で砂州の淡いうねりが「何かある」と読める（前回より明確）。`mobile-touched.png` 相当（砂州の左をタップ後 1.4 秒）で輪が歪むが**直線の角が出ない**。`?demo=1` の 20 秒以内、mobile viewport で `dataset.bar` の x が常に `[rx/幅+0.04, 1−rx/幅−0.04]` に収まる。コンソールエラー 0。
2. **響の手紙（URL が楽譜）最小版**
   - 演奏のタップ（ドラッグ・長押しは対象外）を直近 **8 回**まで記録（x・y を 0〜255 に量子化、強さ＝0〜255、間隔 dt を 0〜255＝約 0〜4 秒に量子化）。`history.replaceState` で `#w=<base64url>` を更新する（**800ms デバウンス・履歴を汚さない**）。幽霊の指の演奏も記録してよいが、デモ中に URL を無限に書き換えないこと（デバウンス必須）。
   - 起動時に `#w=` があれば（壊れていれば try/catch で無視して通常起動）、最初の幕の**代わりに**、その演奏を幽霊の指で一度だけなぞる。再生終了後は通常の水面（デモでなければ静か）に戻る。最初の 1 打は起動 3 秒以内に必ず鳴ること（3 秒ルール）。
   - 再生中だけ、既存のヒント要素の文言を「だれかの水面」に 2 秒だけ差し替える（新しい要素は足さない。390px で 1 行に収まる）。
   - `document.body.dataset.letter = "n=<記録数>;len=<ハッシュ長>"`、再生中は `dataset.letterPlay = "1"`、終了後 `"0"` を公開。
   - 受け入れ条件: probe で `[{"goto":"/"},{"clickAt":[300,380]},{"wait":300},{"clickAt":[700,300]},{"wait":300},{"clickAt":[900,500]},{"wait":1200},{"eval":"location.hash"},{"eval":"document.body.dataset.letter"}]` が `#w=` で始まり n=3。続けて `{"goto":"/#w=<上で得た値>"}` の 1.5 秒後・5 秒後のスクショで、**記録した位置**付近に輪が立ち、`dataset.letterPlay` が `"1"`→`"0"` に変わる。`?demo=1` の 20 秒で `location.hash` が数回以下しか書き換わらない（デバウンス）。コンソールエラー 0、`?fallback=1` でも壊れない。
3. **`shots.json` に 1 ショット追加**: `letter-play`（`#w=` 付き URL で開き 1.5 秒後）。既存ショットは変えず、**追加行のみの最小差分**（改行コードを変えない）。

## やらないこと
- 共有ボタン・コピー UI・シート・ダイアログ・QR・短縮 URL・署名・有効期限。
- ドラッグ・長押し・ムード・石位置の記録（タップ 8 回のみ）。
- 砂州の形・数・ドラッグ移動の変更、`uK` を 0.30 より下げること。
- 石の仕様変更、波速・減衰・解像度・拡散係数の変更、追加 GL パス、追加フェッチ、常時 rAF、`readPixels`。
- 新規ライブラリ。外部通信。

## 見た目・UX の要求
- デスクトップ 1280×800: 初画面は石＋淡いが読める砂州＋星屑。静か。UI は 1 つも増えない。
- スマホ 390×844: 砂州は画面内に収まり、「響」・バー・石と重ならない。ヒント「だれかの水面」は 1 行・切れない・バーと干渉しない。
- 受け手の体験: 手紙を開く → 3 秒以内に最初の輪と音 → 数打なぞられて静かに終わる。説明文は出さない。
- 通常起動（`#w=` なし）の体験は変えない。

## デモモード
- `?demo=1`: 従来どおり幽霊の指が演奏（記録は更新されてよい）。`?demo=1#w=<値>` でも再生が優先され、壊れない。
- 再生確認: `[{"goto":"/?demo=1"},{"wait":6000},{"eval":"location.hash"},{"goto":"/#w=<得た値>"},{"wait":1500},{"shot":"a"},{"eval":"document.body.dataset.letterPlay"},{"wait":5000},{"eval":"document.body.dataset.letterPlay"}]`。
- 不正値の確認: `{"goto":"/#w=!!!"}` でコンソールエラー 0・通常起動。

## 作業役への注意
- 失敗しやすい点: ① 記録の量子化が粗すぎて再生位置がずれる → 位置は 1/255 で十分。② `replaceState` の連打 → デバウンスと最大 1 回/秒。③ 再生中にユーザーが触れたら、再生は中断して通常に戻す（ユーザー優先）。④ 砂州の可視性を上げすぎて泡に見える → 縁なし・加算のみ、暁／夜でも確認。⑤ 手紙の再生が `firstAct` と二重に鳴る → `#w=` があるときは `firstAct` を使わない（無いときの挙動は不変）。
- 屈折の折れが直らない場合の退路: ぼかしをさらに広げる。それでも直線が残るなら `uK` 最低値を 0.33 まで上げる（上げるのは許可、下げるのは禁止）。
- REPORT には、`location.hash` の実例（長さ）、`dataset.letter` の値、再生で輪が立った位置、mobile の `dataset.bar` の x の最小・最大、砂州の可視性を変えた倍率を書く。未確認は「未確認」と書く。
- コミットに Claude を貢献者として入れない。`comms/VISION.md`・`comms/STATE.json` は触らない。
