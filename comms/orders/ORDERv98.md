# ORDER v98  (mode: normal)
## 目的
「響」周りに出る角張った暗い箱と輪の的化をなくし、mobile で濁る金を整えて、画面の端の仕上げを Apple 水準にする。

## やること
1. **「響」周りの角張った影を消す（最優先）。** 症状: desktop-rebound-ring の左上 0〜90px に直線の縁を持つ暗い四角と輪の断片。mobile-meet-spark では「響」が輪に囲まれ光の的になる。
   原因候補: 水面 WebGL の端の屈折・ループ光（loop.js / afterimage / aura）が画面左上隅に寄る処理。丸くない縁が出る箇所を特定する。
   方針: 画面端〜隅（短辺の 12% 以内、「響」周辺 200px 四方）では、ループ光・屈折・凹みの描画を 0 に落とす（c97 の金と同じ条件分岐を使う）。
   受け入れ条件: desktop / mobile の rebound-ring・meet-spark・meet-off・loop-cycle で、「響」周辺に四角い影・輪・光が一切無く、文字だけが静かに見える。
2. **mobile の金の色を直す。** 症状: mobile-meet-spark の金の輪が濁ったオリーブ。青の上に加算で乗って色が濁るのが原因と思われる。
   方針: 金を混ぜる式を desktop と同じ鮮やかな色（暖色の明るい金）にし、青との混色で緑に寄らないようにする。直せなければ mobile 幅では金を出さない（青だけで澄ます）。
   受け入れ条件: mobile-meet-spark / mobile-caustic-ring で、金は鮮やかな金色か、無し。オリーブ・芥子色が無い。
3. **出会いの粒を読めるように。** 受け入れ条件: desktop / mobile の meet-spark で、2 つの輪の交点に半径 6px 以上の明るい粒が 1 つ、周囲より明確に明るく写る（輪の上の泡に見えない、白い点が単独に浮かない）。粒の位置が交点から大きくずれる場合は、接点の計算を実際の輪の半径に合わせる。
4. shots.json は既存のまま使い、NOTES.md を更新する。

## やらないこと
- 新機能・UI・ラベルの追加、色の全面作り直し、他の案（凪の一音・指の腹・張る）の実装。
- 3 が時間内に終わらない場合は 1・2 だけを完了させる。

## 見た目・UX の要求
- desktop(1280×800)/mobile(390×844): 四隅と「響」の周りが青く澄み、直線的な縁・箱・金が無い。ホームは不変（文字・要素を増やさない）。

## デモモード
`/?demo=1&seed=1&hour=13`（既定）と `&meet=0`。
