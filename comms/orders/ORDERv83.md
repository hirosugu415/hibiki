# ORDER v83  (mode: normal)
## 目的
潮の門の最終調整。静止時は堤が完全に見えず、波が通ったときだけ「半円が出る」状態にする。達成できなければ既定 off に戻す。
## やること
1. **静止時の継ぎ目ゼロ**: 堤の陰影・明暗を静止時はほぼ0にし、波の屈折・反射としてだけ効かせる。
   受け入れ条件: `mobile-home` と `desktop-home` で、堤の位置に水平の継ぎ目・帯・筋が一切見えない（現状 mobile の y≈400 に継ぎ目）。
2. **半円を読めるように**: 門の通過部で波の振幅を保ち（減衰をさらに弱める／門幅を広げる／門の下側の持続を延ばす）、`gate-split` で門から出る半円を明確にする。堤の上側は欠けた輪のまま。
   受け入れ条件: `gate-split`（堤の直上、約1秒後）で、mobile・desktop とも門の下に「中心が門の弧」と分かる半円が、輪の約半分の明るさで見える。石より弧が主役。反射を上げて上側を荒らさない。
3. **撮影の修正**: `shots.json` の gate-off 系 eval を `dataset.gate` が無くても落ちないようにする（`?gate=0` で gate が無いことを確認する eval に変える）。
   受け入れ条件: 警告なしで gate-off が撮れる。
4. **撤退条件**: 2 が読めなければ、既定を off（`?gate=1` で opt-in）に戻し、REPORT に理由を書く。
## やらないこと
UI追加、堤の複数化、泉・bowl・石・雨・空の調整、他の新機能。
## 見た目・UX の要求
desktop・mobile 縦とも、静かで波だけが主役。1タップ目の輪と音が先に返る。
## デモモード
`/?demo=1&seed=1&hour=13&gate=1` と `?gate=0` を probe で並置確認。
