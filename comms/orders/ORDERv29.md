# ORDER v29  (mode: normal)
## 目的
IDEAS 案A「砂紋」を実装し、砂の粒が波に反応して畝を作り、格子感が消えた絵にする。

## やること
1. **砂が波に反応する**（`wave-gl.js` RENDER の砂ブロック）。粒の中心で `uState` を 1 回読み、波高 `h` と勾配に応じて粒の**密度（不透明度 keep）と半径**を増減する（輪の直前は濃く寄り、直後は疎ら）。位置の変位は使うとしても ±1.5px まで（c26 の欠けの失敗を避ける。**密度で畝を表すのが本命**）。静かな水面では今と同じ見た目。
   - 受け入れ条件: 同じ位置で `drift-early`（打の 0.35 秒後）・`drift-late`（+0.9 秒）・`drift-rest`（+4 秒）の 3 枚を撮り、early/late では輪の位置の砂が**線状に濃く、その内側が薄い**と肉眼で分かり、rest では元に戻っている。
2. **格子感を壊す**。4px 単一格子をやめ、周期の合わない 2 枚（例 4px と 5.3px、約 17° 回転）を重ねて半分ずつ間引く。セル内オフセットを ±0.45 セルに、半径を 0.9〜1.6px でばらし、低周波ノイズで密度に斑を付ける。総粒数は現状と同程度（負荷を増やさない）。
   - 受け入れ条件: `drift-rest` と mobile-touched で縦横の十字線・規則的なドット列が見えない。節の線（図形）は今のまま読める。
3. **証拠の撮影**。`app/shots.json` に `drift-early` `drift-late` `drift-rest`（desktop・mobile 両方、同じ clickAt）を追加。`document.body.dataset.sandDrift = "最大変位px,波頭の数"` を出す（CPU 側で輪の半径と波速から見積もり）。

## やらないこと
- 新しい UI・文字・ボタン（バーは 4 個のまま）。石・砂州・夜光虫・手紙・ムードの変更。案B/C の実装。ライブラリ追加。輝度上限や色の変更。

## 見た目・UX の要求
- デスクトップ・スマホ共に初画面（触れる前）の静けさは変えない。畝は繊細に（白飛び・ちらつき禁止）。mobile 390×844 は粒が間引き済みで畝が太めになるので、太すぎないよう調整。タップ→音→輪の 3 秒体験は不変。

## デモモード
`?demo=1` の幽霊の指の打がそのまま輪を作る。probe 例: `[{"goto":"/?demo=1"},{"wait":2500},{"clickAt":[820,420]},{"wait":350},{"shot":"drift-early"},{"wait":900},{"shot":"drift-late"},{"wait":4000},{"shot":"drift-rest"},{"eval":"document.body.dataset.sandDrift"}]`

## 作業役への注意
- c27 の教訓: 「効いたはず」は証拠にならない。3 枚を自分で開いて差が見えなければ、係数を上げて見えるまで調整してから REPORT に書く。差が見えない場合は正直に書く。
- 変位でセル境界の欠けが出たら即やめて密度のみにする。REPORT には 3 枚のどこで何が見えたかを具体的に書く。
- 重くなったら粒数を間引く（60fps 優先）。コンソールエラー 0 を維持。
