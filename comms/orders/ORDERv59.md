# ORDER v59  (mode: normal)
## 目的
夕の上端を「オレンジの帯」から、下へ溶ける滑らかな琥珀のにじみにする。刻の水の色仕上げはこのサイクルで終える。

## やること
1. **夕の帯を伸ばして薄くする**（`app/src/moods.js` HOUR_KEYS h:19、`app/src/wave-gl.js` 空の映り込み部 line ~172、`app/src/main.js` palT）。
   - R の乗算を 4.3 から 2.6〜3.2 程度に下げ、強さを落とす。
   - 空の帯の高さ `uSky.y`（hb）を時刻で伸ばす。HOUR_KEYS に任意の `band`（昼=1、夕=1.6、朝=1.25、夜=1.0）を足し、hourTint で補間して main.js から wave-gl の uSky.y に掛ける（昼は恒等）。
   - 受け入れ条件: desktop-hour-evening で、上端から y≈25% まで色が連続的に減衰し、帯の下端に境界線も暗い谷も見えない。上端 12% 平均は R>B かつ G<R、輝度は c58 より 15% 以上低い。mobile-hour-evening も同様に塗られた感じが消える。
2. **帯の下の暗い谷を緩める**（wave-gl.js の vignette 行）。夕（band>1）のとき、上端側（uv.y>0.55）の暗縁を弱める。
   - 受け入れ条件: 夕の上端 5%〜30% の輝度が単調に変化し、途中で昼より暗い谷が出ない。中央〜下（40–90%）は hour=13 と ±3% 以内。
3. **朝・夜の差を上端だけ一段強める**（HOUR_KEYS h:6 と h:1 の mul/add のみ。加算上限 0.08）。
   - 受け入れ条件: hour=6 と 13 の上端 12% 平均の ΔRGB ≥ 30、hour=1 は 13 より輝度 −25% 以上で青のまま。中央〜下は ±3%。
4. 8 時点（0,3,6,9,13,16,19,22）の上端 12% 平均 RGB を REPORT に表で載せ、隣接で段差がないことを示す。13→16 の R の急上昇も緩める。
5. NOTES.md に新しい値と `band` を追記。

## やらないこと
- 新UI・文字・ボタン、ムード追加、新パス、残響・音階の係数変更。
- 中央〜下を明るくすること。外部通信・位置情報。

## 見た目・UX の要求
- desktop: 夕は上端が熱くならず、夕焼けの余韻のように下へ溶ける。朝は冷たく淡く、夜は深い。
- mobile: 上端が塗られた印象を出さない。hk=1.9 の増幅は、必要なら band 側に吸収してよい。
- hour=13 の home は c58 と同一（回帰ゼロ）。3秒体験は不変。

## デモモード
`?demo=1&seed=1&hour=19` / `6` / `1` / `13` で desktop と mobile を確認。

## 作業役への注意
- 夕は必ず desktop-hour-evening と mobile-hour-evening を目で見て、帯・谷が残っていないか確認する。数値だけで判断しない。
- 受け入れ条件を守れない場合は、守れなかった値と理由を REPORT に書く。
- 上端 20% を hour=6/13/19/1 で並べたスクショと数値を REPORT に示す。
