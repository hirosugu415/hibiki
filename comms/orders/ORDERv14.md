# ORDER v14  (mode: normal)

## 目的
石を「黒い穴」から「水に浮かぶ濡れた小石」へ磨き、石の存在に気づく手がかり（縁のさざ波）を加え、公式スクショで回折の証拠が撮れるようにする。

## 現状（司令塔の評価: 7/10、v13 コミット済み、ヘルス OK）
- 石の物理（反射・回折・ドラッグ・応答音・幽霊のずらし）は動く。自分で触って確認（`probe` t300: 石の手前で輪が欠け、影側は静か）。
- 弱点: (a) `desktop-idle.png` の石が均一な暗い塊で「穴／インクの染み」に見える。(b) 石を触れる手がかりが初見ライブでは皆無。(c) `stone-shadow` スクショは 1100ms 後で波が消えており証拠にならない。`hold` は `waitFor body[data-holding='1']` が 5s タイムアウト（ghost.js の長押しが約 6.5s 後になったため）。

## やること（優先順）
1. **shots.json の修正（最優先・小さい）。**
   - `stone-shadow`: 待ち 1200 → `clickAt` → 待ち **350〜450ms** で撮影（輪が石に当たっている瞬間）。desktop/mobile 共通座標なので、石（desktop 640,480 / mobile 195,506 付近）の左右どちらかから波が来て、どちらの幅でも石の縁に輪が届く座標にする（例: 330,480 は両方で石から 130〜310px）。余裕があれば同じ画面で 350ms と 800ms の 2 枚（`stone-shadow` / `stone-shadow2`）。
   - `hold`: 長押し開始（約 6.5s）に合わせ、先に `wait 6000` を入れてから `waitFor` するか、ghost.js の最初の長押しを約 4.5s に前倒しする（どちらかでよい）。警告が消えること。
   - 受け入れ条件: `meta.json` の `warnings` が空。`stone-shadow` のスクショに輪が写り、石の縁で欠けている。
2. **石の質感（RENDER、wave-gl.js のフラグメントのみ）。** 濡れた小石に見せる。
   - 内部: 一様な暗色をやめ、上寄りがわずかに明るい縦グラデーション＋ごく淡い斑（既存の模様を活かす）。下側は水に沈む感じで少し暗く。
   - 縁: 全周に均一な青い線ではなく、**左上に細く明るい弧（ハイライト）、右下は薄い**。縁の外側 6〜10px に背景のゆがみ（屈折）を今より少し強く。
   - 波が当たった側の縁だけ光る（現状の挙動）は維持。
   - **禁止**: 塗りつぶし円盤、濃い輪郭線、落ち影の球、`.flash` 的な泡。明るさは控えめ（Apple 的な静けさ）。
   - 受け入れ条件: `desktop-idle.png` / `mobile-idle.png` で、石が「穴」ではなく「水面の上の小石」として読める（ハイライトの弧と内部の明暗差が見える）。背景の星屑・色味となじむ。
3. **石のさざ波（存在の手がかり）。** 起動約 2 秒後に 1 回、その後は放置が続く間 **8〜14 秒ごと**に、石の縁から 1 輪だけごく淡い波が立つ（水に浮いて揺れている）。
   - 実装は既存の「ambient」（main.js 375 付近）またはタップ注入の仕組みを再利用し、強度は通常タップの 1/4 程度。**音は鳴らさない／鳴らしても `stoneHits` は増やさない。常時 rAF は禁止**（波が減衰して静止したら描画停止の既存ロジックを壊さない）。ユーザーが触っている最中・長押し中は出さない。ミュートに関係なく無音。
   - `dataset.stoneLaps`（出した回数）を追加。
   - 受け入れ条件: `?live=1` を 12 秒放置するとスクショで石の周りに淡い輪が見え、`stoneLaps >= 1`。放置後 20 秒で CPU/描画が常時回り続けない（既存の静止判定が働く）。

## やらないこと
- 石の複数化・消去・レンズ化・見た目のバリエーション、物理定数（減衰・`uK`・解像度）の変更、新規 GL パス・新規テクスチャ。
- バーのボタン追加・説明文の追加（UI は増やさない）。
- Canvas2D フォールバックへの石の実装。

## 見た目・UX の要求
- デスクトップ 1280×800 / スマホ 390×844 両方で、石が背景に馴染み、バー・ヒント・「響」と干渉しない。
- 石の掴みやすさ（半径+10px、最小直径 88px 相当）とドラッグの慣性は現状維持。
- さざ波は「気づく人だけ気づく」程度の控えめさ。目立たせすぎない。

## デモモード
`?demo=1` で従来どおり幽霊の指が石を扱う。さざ波の確認は `?live=1` の放置（`stoneLaps`）。カメラ・マイク不要。
