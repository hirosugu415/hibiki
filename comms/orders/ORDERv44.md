# ORDER v44  (mode: innovation)
## 目的
実装はしない。砂線・残像の次に体験を一段引き上げる案を3つ、`comms/IDEAS.md` の末尾に追記する。

## やること
1. `app/NOTES.md` と現在の機能（波紋・石・砂・ムード・残像・ガラスのバー）を踏まえ、他の楽器アプリにない案を **3つ** 書く（案A/B/C）。各案に: 一行の要約、ユーザーが体験する流れ、独自性、規模（S/M/L）、実装の要点（ファイル・手順）、デモモード（`?demo=1&seed=1`）での確認方法、リスクと退路、自己チェック（説明文なし / 3秒 / 静けさ）。
2. 末尾に「作業役の推し」を1案、理由つきで書く。
3. 発想の領域: VISION の「長く育てる軸」のうち、まだ弱いもの —— **演奏の記録とループ、作品の保存と書き出し、入力（マイク・傾き）**。このうち少なくとも2案はここから。残り1案は自由。
4. 発想の制約: UI 文字を増やさない（アイコン・動きで伝える）。バーは現状の3ムード+音量を大きく変えない。localStorage のみ・外部送信なし。静止画2枚＋`document.body.dataset` で白黒がつくこと。

## やらないこと
- app/ のコード変更（砂線の調整も含め一切しない）。ライブラリ追加。既存案（撚り・残像・触れ方で変わる水）の焼き直し。

## 見た目・UX の要求
- 案は desktop・mobile 両方で成立し、home の静けさと3秒以内の最初の体験を壊さないこと。

## デモモード
- 各案の評価手順を `?demo=1&seed=1` と probe の steps 例で書く。カメラ・マイクが無い前提で、入力系の案は擬似入力で確認できる形にする。

## 作業役への注意
- IDEAS.md は追記のみ（既存部分は変更しない）。**既知の未解決**として、mobile の afterimage 後に輪から石へ走る明るい斜線と、砂の糸状の線が残っている。案に直接含めなくてよいが、案が見た目の粗さを増やさないこと。
