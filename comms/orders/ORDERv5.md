# ORDER v5  (mode: normal)

## 目的
IDEAS 案C「息の水面」の最小版を実装し、**何も触らなくても、開いた瞬間から美しく生きている水面**にする（初見の空虚さを消す）。あわせて「響」の階層とヒントの位置を洗練する。

## 現状（司令塔の評価: 5/10、ヘルス OK）
- 核（触れる→波紋＋音）は成立。ただし `mobile-home.png` は暗い単色グラデに文字と見えない光点だけで空虚。「響」は左上 22px で淡く、ヒントは画面中央固定で波紋の芯に重なる。
- 描画は SwiftShader でも重くならないよう既に絞ってある（v2 の失敗: 負荷を測らず見た目を足して固まった）。**シェーダーの追加パスは禁止**。静止時に rAF を止める現行の省電力（`wake()`）は維持する。

## やること（優先順）
1. **常時そこにある「生きた環境」を CSS の合成だけで作る**（`index.html` に `#aura` 1 要素、`style.css` に実装。JS ループ不要）。
   - 水面の上に、ゆっくり呼吸する大きな淡い光の層を 2〜3 枚（`radial-gradient`、色は `--accent` / `--deep` から取りムード切替に追従）。`transform`/`opacity` のみを `@keyframes` で動かす（周期 9〜14 秒、ずらして重ねる）。`will-change: transform, opacity`、`pointer-events: none`、キャンバスより上・UI より下。
   - 微粒子（光の塵）を 10〜14 個: 小さな円（2〜4px、ぼかし、opacity 0.15〜0.45）がゆっくり漂い瞬く。位置・周期は固定の配列かカスタムプロパティでばらつかせる。`transform`/`opacity` のみ。
   - 受け入れ条件: `?demo=1` でも `/` でも、起動 2 秒後の `mobile-home.png` と `desktop-home.png` で、画面全体に淡い光の濃淡と複数の微粒子が見え、「空っぽの単色グラデ」に見えない。ただし派手すぎず、波紋・ヒント・バーより目立たない（Apple 的な抑制）。`prefers-reduced-motion` では動きを止めて静的な光だけ残す。
2. **間欠の雨粒（音付き）**: 触れられていない間、7〜11 秒に 1 回、画面内のランダムな位置（バーとヒント領域は避ける）に弱いインパルス（既存 `ripple()`）＋最小音量・高音域の短い一音（既存 `note()` を小さな `vel` で）。ユーザーが操作した直後 8 秒は出さない。デモでは幽霊の指が既に鳴らすので重複させない（`DEMO` では雨粒を出さない）。
   - 受け入れ条件: `/`（非デモ）を放置すると 8〜12 秒以内に小さな輪が 1 つ立つ（`document.body.dataset.ambient` に累計数を出す）。rAF は雨粒の波が収まった後に再び止まる（`wake(LIVE)` 内で完結、常時ループにしない）。コンソールエラー 0。
   - 注意: 音は `audio.unlock()` 前は鳴らなくてよい（ブラウザ制約）。無音でも波紋だけ立つこと。
3. **ブランドとヒントの洗練**
   - 「響」: 左上 22px → 28〜32px、少し明るく（opacity .75 前後）、字間と上下の余白を整え、`env(safe-area-inset-top)` を考慮。細字で上品に。
   - ヒント「触れてみてください」: 画面中央固定をやめ、**ガラスバーの少し上**（バー上端から 28〜40px）に置く。波紋・光の芯と重ならない。出入りは opacity＋わずかな translateY のゆっくりした 600ms 前後のフェード。タップ後は消える現行挙動を維持（`gone`）。
   - 受け入れ条件: `desktop-calm-after.png` でヒントが光の芯と重ならず、`mobile-home.png` でバーの直上に収まる。「響」が一目でワードマークと分かる。
4. **暁のバーのコントラスト**: 暁ムードで非選択ラベル（凪/夜）とアイコンの不透明度を上げ、`mobile-mood-dawn.png` で読める（背景との明度差を現状より明確に）。選択インジケータはそのまま。

## やらないこと
- マイク入力・ポインタ追従のうねり・録音/ループ（案A）・媒質切替（案B）。許可ダイアログは出さない。
- 新しいシェーダーパス、解像度の引き上げ、`wave-gl.js` の大きな変更。常時 rAF ループ化。
- 新しい UI ボタンの追加（バーは現状維持）。ムードの追加。
- 外部 API・通信・ライブラリ追加（CSS と既存コードのみで足りる）。

## 見た目・UX の要求
- デスクトップ 1280×800: 光の層は端まで滑らかに満ちて切れ目が見えない。粒子が中央のヒントや下部バーに被って読みづらくならない。
- スマホ 390×844: 粒子と光の層で横スクロールが出ない（`overflow:hidden`）。親指で届く下部にヒントとバー。タップ領域 44px 以上を維持。
- 全体で「静かで上品」。コントラストの強い点滅・派手な色は禁止。ムード（凪/夜/暁）を切り替えると、光と粒子の色も約 1 秒でなじむ。
- 日本語ラベルは短く、英語を混ぜない。

## デモモード
- `?demo=1` で、環境光と微粒子が常に見える。幽霊の指の演奏と環境が干渉して汚くならない（環境は淡く）。
- `shots.json` は現行の 5 シーンを維持。必要なら `home` の待機を 2500ms のままにし、環境が起動直後から写ることを確認する。非デモの確認用に、`shots.json` に `{ "name": "idle", "url": "/", "steps": [ { "wait": 11000 } ] }` を 1 つ追加してよい（雨粒の出現確認用）。

## 作業役への注意
- v2 の失敗を繰り返さない: **変更後に必ず `npm run build` と、`?demo=1` / `/` を各 15 秒放置してのフレーム落ち確認**（rAF が止まるか、止まらない場合はなぜか）を REPORT に書く。`animation` は `transform`/`opacity` のみ（`filter: blur` のアニメ・`box-shadow` のアニメは不可）。ぼかしは静的な `radial-gradient` で表現する。
- CSS アニメは `visibility:hidden` のタブでは止まるが、それ以外は常に動く。要素数は粒子 14 個以内・光の層 3 枚以内に固定する。
- REPORT には、スクショで確認した事実（home がどう変わったか）と、測れなかったことを分けて書く。
- コミットに Claude を貢献者として入れない。`comms/VISION.md` と `comms/STATE.json` は触らない。
