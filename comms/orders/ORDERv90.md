# ORDER v90  (mode: normal)
## 目的
c89 の底の光を「灰褐色の縁取り」から「透明感のある金の光が輪の内側に屈折して落ちる」見た目に直し、mobile でも1打で一目で読めるようにする。

## やること
1. **色の修正**（wave-gl.js の caustic 合成部）: 現状はベージュ/灰褐色に見える。足す色を彩度の高い淡い金（昼: 例 R1.0 G0.82 B0.45 付近、乗算ではなく加算寄りで青を潰さない）にし、輝度は据え置きか低めに。夜（hour=20）は赤みの強い琥珀（R1.0 G0.62 B0.28）に明確に切り替える。
   受け入れ条件: `/?demo=1&seed=1&hour=13` の最初の1打約1.2s後、desktop-caustic-ring で帯が「金色」と呼べる色相に見え、灰色・泥色に見えない。hour=20 では昼より明らかに赤い。R−B の最大値を desktop/mobile、hour=13/20 の4通りで REPORT に数値で書く。
2. **屈折オフセット**: 底光のサンプル位置を、既存の法線（水面勾配）方向に数 px〜十数 px ずらして計算し、波頭の線の真上ではなく輪の内側へ少しずれて落ちるようにする。サンプリングは既存の env>0 の間の追加読み取り内で行い、追加パスは作らない。
   受け入れ条件: desktop-caustic-ring で、青い輪の線と暖色の帯が完全には重ならず、内側に光が落ちている二重構造に見える。
3. **mobile の強化**: viewport 幅が小さいとき強度・帯幅を補正し、mobile-caustic-ring を caustic-off と並べて肉眼で一目で差が分かるようにする（desktop の R−B 差の 70% 以上を目安）。細い線にしない（帯幅 6px 以上の柔らかいシート）。
4. **制約維持**: 白飛びなし（最大チャネル 251 以下）、ホームの放置時は c89 と同一の静けさ、dataset.caustic・?caustic=0・?caustick・?causw は維持。shots.json は caustic-ring / caustic-off を維持し、`hour=20` 用に `caustic-night`（desktop・mobile）を追加。

## やらないこと
UI追加、文字追加、波動 SIM 係数の変更、新しい操作、保存形式の変更、殻・石・ムード・バーの見た目調整、2D フォールバックへの対応。

## 見た目・UX の要求
- desktop: 青い水面の輪の内側に、金の柔らかい光が屈折して落ちる。ギラつかず上品。石の影・ワードマークより暗い。
- mobile(390×844): 1打で光の帯が読める。ホームは c89 と同一。
- 約2〜3秒で消える挙動、60fps 近さを維持。

## デモモード
`/?demo=1&seed=1&hour=13` と `hour=20`、`?caustic=0` との並置で確認。

## 作業役への注意
- 「淡い」「控えめ」で止めない。静止画1枚で見えることが合格線（c81–83 の轍）。一方で明るすぎて泡・発光になったら帯を広げ輝度を下げる。
- 色の確認は R−B だけでなく画像を自分で見て「金色か」を判断し、REPORT に一言書く。
- NOTES.md は4KB台、REPORT は事実のみ。ビルド成功・コンソールエラー0。
