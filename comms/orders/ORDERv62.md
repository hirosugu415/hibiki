# ORDER v62  (mode: normal)
## 目的
c61 で入れた「沈む指」の凹みを、染みにならない範囲で静止画でも知覚できる強さにし、押下の触感を確かに伝える。

## やること
1. **凹みを見えるようにする**: wave-gl の uDent を強化する。半径を短辺比 0.05→約 0.08、勾配の強さを現在の約 2〜3 倍にする（`0.34 * dr * dsh - 0.10 * de` の係数を調整）。勾配（片側が淡く明るく、反対が暗い）だけで表し、縁・塗り・発光・輪郭線は作らない。
   - 受け入れ条件: desktop の press-hold 静止画（押下中・泉が始まる前）で、指の位置に滑らかな凹みの陰影が目視できる。かつ「黒い染み」「泡」「円盤」に見えない。dataset.touch の深さが押下中 >0 で、強化前より大きい値。
2. **press-hold の撮り方を確実に**: 押下 110〜150ms の時点で凹みが最大に近く、泉・タップ輪と重ならない位置を選ぶ（輪が画面中央付近の凹みと重なるなら、タップ輪を凹み時に小さく抑えるか、撮影位置をずらす）。desktop・mobile の両方で撮る。
   - 受け入れ条件: shots に `press-hold` と、凹み周辺だけを 3 倍に拡大した `press-hold-zoom`（desktop・mobile）がある。
3. **mobile で見える大きさ**: 指が隠しても周囲に陰影の縁（約指の半径の外側）が見えるよう、mobile では半径を少し大きく（短辺比 0.09〜0.10）する。
   - 受け入れ条件: mobile-press-hold で指位置の周りに淡い陰影が見える。
4. **回帰確認**: 通常タップ（<160ms）の輪は 1 つで離音なし、home は不変、泉・石・砂への影響なし。
   - 受け入れ条件: `?demo=1&seed=1` でコンソールエラー 0、home のスクショが c61 と視覚的に同一。

## やらないこと
- 時刻・空・色味・文字・ボタン・新 UI の追加。分光・音の連動。
- 凹みへの輪郭線・発光（c25/c42 の教訓）。
- 新しい世界観や機能の追加。

## 見た目・UX の要求
- desktop・mobile とも home は不変。凹みは押下中のみ、離したらなめらかに消える（反動の輪は従来どおり 1 つ）。
- 3 秒体験（1 タップ→輪＋音）を遅くしない。

## デモモード
- `?demo=1&seed=1` の幽霊の指の長め押下（約 12.7s）で再現。手動は probe で pointer down を保持して 150ms 後に撮る（drag は離してしまうので注意）。

## 作業役への注意
- 強くしすぎて「染み」に寄ったら 1 段戻す。基準は「拡大しなくても陰影があると分かるが、輝度の中心は動かない」。
- 定数（半径・強さ）は dataset.touch に出して評価者が値で確認できるようにする。
- 終える前にコンソールエラー 0 と home 不変を確認する。
