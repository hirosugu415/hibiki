# ORDER v49  (mode: normal)
## 目的
触れずにいる水面に「雨」という天気を与える。放置で小雨→本降り、触れると退き、止めると雨あがり。UI・文字は増やさない。

## やること
1. **雨の核（main.js、既存の `quietTap` 経路を使う）**
   - 無操作時間 `idleSec` から `rain`(0..1) を決める: 40s 未満は 0（home と 3 秒体験は完全に不変）。40s 以降ゆっくり立ち上がり、**90s までは drizzle（rain≤0.35）に上限**。以降は rain まで。
   - 雨粒＝ランダム位置（seed 付き乱数、石の周囲は避ける）の弱い打。`tap(x,y,vel,false)` を `quietTap=true` で呼ぶ（残像・覚える水に記録しない）。vel は小さく、**同時に生きる雨輪は最大 6 個**。間隔は drizzle で 2〜4s、rain で 0.6〜1.5s。
   - 音は既存 note を極小音量（通常の ≤15%）。ミュート中は無音（視覚のみ）。
   - 受け入れ: `?demo=1&seed=1&rain=1` で rain=0.8 から開始し、静止画に重なる小さな輪が見える。輪は既存と同じ質感で、振幅は通常タップの 1/3 以下。糸・筋・白点が出ない。
2. **触れると退く／雨あがり**
   - ポインタ入力で rain は 2s 以内に 0.2 未満へ。触れて手を止めると `weather="clearing"` が約 6s 続く（この間、水面の輪の減衰を少し緩める＝既存の damping を 0.5% 以内で調整、または輪が長く残る程度。無理なら見た目変更なしで dataset のみ）。
   - 受け入れ: tap 直後 2s の `dataset.rain` < 0.2、数秒後に `weather` が clearing → dry。
3. **dataset と shots.json**
   - `document.body.dataset.rain = "0.00".."1.00"`、`dataset.weather = dry | drizzle | rain | clearing`。
   - shots.json に `rain-drizzle`（`?demo=1&seed=1&rain=0.3`）と `rain-heavy`（`rain=1`）を desktop・mobile で追加。既存 shots は `rain` 無しで従来と同一であること（回帰確認）。

## やらないこと
- UI・文字・ボタンの追加、ライブラリ追加、石・砂・残像・手紙のロジック変更、雨専用の新シェーダ。
- 雨の視覚強化（霞・色変化・水面の明暗変化）。輪のみ。

## 見た目・UX の要求
- desktop・mobile とも、home（`rain` 無し）は c47 と同一。本降りでも画面が白飛び・ざわつきしない。雨輪は石・砂線・夜光虫を覆わない。
- 雨が降り始めて最初の 1 粒が「突然」にならないよう、立ち上がりは緩やかに。

## デモモード
- `/?demo=1&seed=1` は従来通り。`&rain=0.3` / `&rain=1` で雨を即時開始（無操作待ち不要）。`dataset.rain` / `dataset.weather` で白黒。

## 作業役への注意
- ヘッドレス評価は無操作が続く。通常 shots の撮影が 40s を超えて雨が混ざらないよう、雨は無操作 40s 以降のみ、かつ `?demo=1` の ghost 演奏中は雨を止める（rain=1 指定時を除く）。
- 輪の同時数上限 6 と振幅の低さが最優先。粗く見えるなら降らせない方を選ぶ。
- コンソールエラー 0、`app/NOTES.md` に 1 行追記。
