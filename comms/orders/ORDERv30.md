# ORDER v30  (mode: normal)
## 目的
砂を「格子上の離散点」から「画素単位の細粒ノイズによる連続した砂の帯」に描き直し、点線感を消して波頭で畝が見えるようにする。

## やること
1. **格子を廃止して画素ノイズに**（`wave-gl.js` 砂ブロック）。粒中心・セルのループをやめ、各画素で節線までの距離 `d`（既存の plate 量から）を使い、帯の濃さ `band = exp(-(d/w)^2)`（w は 1.5〜3px。スマホは少し細く）を出す。その上で画素ごとのハッシュ（device px 単位・2 オクターブ）と比較して粒状に抜く（`step(noise, band)`）。結果は「細かい粒が詰まった、縁がほどける線」。丸い点は出さない。
   - 受け入れ条件: desktop-home・mobile-touched・drift-rest で、規則的なドット列・縦横の直線状の点線が見えない。拡大せずに「砂の線」と読め、点の数を数えられない細かさであること。節線の図形（曲線）は今のまま読める。輝度上限・色は変えない。
2. **波頭で畝が見える**。波高 `h` と勾配で、帯の幅 w を ×0.6〜×1.8、濃さを ×0.5〜×1.6 に変える（山で締まって濃く、谷で広がって薄く）。位置のずれは ±1px まで。
   - 受け入れ条件: 同じ位置の砂の線が通る場所で `drift-early` と `drift-late` を撮り、輪が通る部分だけ線の太さ・濃さが変わっていると肉眼で分かる（2枚を並べて違いを REPORT に具体的に書く）。
3. **復帰の証明**。砂が消えない状況で撮れるよう、drift 3枚の直前に砂を保つ操作（既存の plateTouch 相当を eval で呼ぶ等、新 UI なし）を入れ、`drift-rest` でも砂の線が見えて、輪が去ったあと元の太さに戻っていること。`shots.json` の drift-* を更新。
   - 受け入れ条件: drift-rest に砂の線があり、early/late の乱れが無い。

## やらないこと
- 新 UI・文字・ボタン（バーは 4 個のまま）。石・砂州・夜光虫・手紙・ムードの変更。ライブラリ追加。色・輝度上限の変更。音の変更。

## 見た目・UX の要求
- 初画面の静けさを保つ。白飛び・ちらつき禁止（ノイズは時間で動かさない＝画面に固定。動くと砂がざわつく）。mobile 390×844 は帯が太すぎないこと。タップ→音→輪の 3 秒体験は不変。

## デモモード
`?demo=1` の幽霊の指の打が輪を作る。probe 例: `[{"goto":"/?demo=1"},{"wait":2500},{"clickAt":[820,420]},{"wait":350},{"shot":"drift-early"},{"wait":900},{"shot":"drift-late"},{"wait":4000},{"shot":"drift-rest"}]`

## 作業役への注意
- 3 サイクル連続で「効いたはず」が静止画で見えていない。必ず early/late/rest と home を自分で開き、差が見えるまで係数を上げてから REPORT に書く。見えなければ正直に書く。
- 画素ごとの計算は軽く保つ（uState の読み取りは画素あたり最大 1 回）。重ければ帯の計算を節線近傍に限定して早期 return する。
- wave-gl.js は全面書き換えにせず、砂ブロックだけを差し替える（差分を最小に）。コンソールエラー 0 を維持。
