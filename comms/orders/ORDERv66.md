# ORDER v66  (mode: normal)
## 目的
分散まわりの安全性を実証して閉じ、輪の水らしい構造を描画側の弱い高周波強調で補う。

## やること
1. **発散ガードの実証**（必須）。URL に `?guardtest=1` を足すと、分散係数を一時的に 0.2 などの危険値にして（上限 0.035 を迂回、テスト専用）ガードが発火することを確認できるようにする。
   - 受け入れ条件: `?demo=1&guardtest=1` で `dataset.disp` の trips が 1 以上になり、その後も画面は白飛び・真っ黒にならず、コンソールエラー 0。通常 URL では guardtest は一切効かない。
   - `?demo=1` で連打・ドラッグ・雨を 30s 続けた後、`dataset.dispMax` が十分小さく、trips 0 であること。REPORT に数値で記す。
2. **ガードのコスト低減**。readPixels の間隔を 2.5s→5s に延ばすか、1x1 に近い小領域のみ読む。mobile で毎フレーム処理に影響しないこと。受け入れ条件: `dispMax` の ms が減る（REPORT に前後の値）。
3. **描画側の高周波強調（ごく弱く）**。輪の高さ場の 2 階差分（ラプラシアン）成分を、既存の縁ゲインより小さく足して、輪の外縁に細い二重線感を出す。
   - 受け入れ条件: `disp-on` の拡大 shot で、`disp-off` より輪の縁に細い構造が見える。home（無操作）は平均輝度 ±1% 以内で不変。筋・泡・ノイズに見えない。`?hf=0` で無効化できる。
4. NOTES.md を 4KB 以内に整理（古い経緯を削る）。

## やらないこと
- sim 解像度の変更、色・空・石の調整、新 UI・文字、新機能。
- 主波の速度・音・音階の変更。

## 見た目・UX の要求
- desktop・mobile とも home は不変で静か。タップ後の輪は繊細なまま、うるさくならない。

## デモモード
- `?demo=1&seed=1` の幽霊の初打 2.5s で評価。比較は `?hf=0` / `?disp=0`。

## 作業役への注意
- guardtest はテスト専用で、既定動作・UI には影響させない。壊れたら高周波強調を既定オフにして退路を確保し、REPORT に明記する。
- 小さく確実に。3 は効果が出なければ係数を少しだけ上げる程度で、深追いしない。
