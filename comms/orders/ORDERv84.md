# ORDER v84  (mode: innovation)
## 目的
潮の門を既定 off に退却させたうえで、「静止画1枚で別物と読める」新しい体験案を3つ IDEAS.md に出す（実装はしない）。
## やること
1. **退却（1行だけ）**: `app/src/main.js` の `GATE_ON = GATE_PARAM !== '0'` を `GATE_PARAM === '1'` に変える。コードは削除しない。ghost の「最初の打を堤の上側に置く」設定も gate off 時は通常配置になること（既に分岐があるなら確認のみ、無ければ触らない）。
   受け入れ条件: `/?demo=1&seed=1&hour=13` で `document.body.dataset.gate === 'off'`、`?gate=1` で従来どおり on。ビルド成功・コンソールエラー0。`shots.json` の gate-split は URL が `gate=1` 付きなので変更不要。NOTES.md に「既定 off（c84）」と一行。
2. **発想**: `comms/IDEAS.md` の末尾に `## Cycle 84 — 提案 (builder)` を追記し、案A/B/C を書く。各案: 体験（誰が何をして何が起きるか）／静止画での差（スクショ1枚で伝わるか）／規模（S/M）／デモでの確認方法（URL・dataset）／退路／最大リスク。最後に「作業役の推し」を1つ。
   領域の指定（3案は互いに別領域にすること）:
   - 領域X: **ホーム画面の最初の3秒**。何も触らずに眺めているだけで「ここは特別な場所だ」と分かる、文字・UIを増やさない演出。
   - 領域Y: **音の側**。見た目は同じ波でも「音だけで別物」になる軸（和音の積み方、残響の質、水中/空中の切替など）。デモでは dataset やコードで確認できること。
   - 領域Z: **持ち帰り**。演奏の結果が1枚の美しい画像・URL・手触りとして残る／戻ってくる動機になる仕組み（既存の letter/share と重複しない新規性）。
   却下済みで再提案しない: 払う（Sweep）、昨日の返事は修正再提案なら可。潮の門の再提案は不可。
## やらないこと
上記1行以外の app/ 変更、UI追加、新機能の実装、見た目の調整。
## 見た目・UX の要求
退却後の desktop・mobile home が現状（静かで波が主役）と同じであること。
## デモモード
`/?demo=1&seed=1&hour=13` で gate が off、`?gate=1` で on を probe で確認。
## 作業役への注意
- 案は「あると嬉しい」程度でなく、スクショ1枚で白黒つくものだけ。3サイクル磨いても読めなかった潮の門の轍を踏まない（受け入れ条件は静止画で判定できる形に）。
- 事実だけを REPORT に書く。NOTES.md を更新。
