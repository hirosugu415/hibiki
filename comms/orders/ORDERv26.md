# ORDER v26  (mode: normal)
## 目的
砂の図形（c25 で成立）の**質感を Apple 水準に磨き**、スマホで静かにし、波が通ると砂が応える。新機能は足さない。

## やること（優先順）
1. **粒を丸く柔らかく**（`wave-gl.js`）。四角いセルのドット絵に見える点を、セル内の smoothstep の円形粒に変える。粒ごとに明るさを hash でばらつかせ（0.6〜1.0）、dpr を考慮して 2px 相当を保つ。輝度上限 0.5 は維持、線は静止画で読める強さのまま。
   - 受け入れ条件: desktop-plate-high / mobile-plate-low を拡大して見たとき、破線状・四角の点ではなく、細かい丸い砂粒の連なりに見える。全面の雪・ノイズに見えない。
2. **スマホで静かに**: 縦長（短辺<600px）では (n,m) を表から 1 段粗い組に寄せるか線幅を細く・量を下げて、線の密度を今の約 6 割にする。「響」の周り・バー周り（下 120px）・ヒント文の周りは砂を弱める（今のバー付近の抑制を広げる）。
   - 受け入れ条件: mobile-plate-high で「響」と「触れてみてください」が砂に埋もれず読める。隣り合う音高で図形が変わる性質は維持。
3. **波が通ると砂が応える**: 既に読んでいる水面の高さ（追加パス・追加テクスチャ読み取りは禁止）で、波頭の通過位置の砂粒の輝度を最大 +0.15 持ち上げ、位置を 1px 程度だけ揺らす。
   - 受け入れ条件: desktop-touched で、輪の通る帯だけ砂がわずかに明るい。輪のない所は変化なし。
4. **shots の修復**: `desktop-hold` の `waitFor body[data-holding='1']` が 5 秒タイムアウト（警告）。幽霊の指が長押しするタイミングを待てるよう waitFor を延ばすか、probe で合う条件に変える。`hold` 画面で泉と図形保持が写ること。wait 合計は増やさない（他の待ちを削る）。

## やらないこと
- バー・ボタン・新 UI・新ライブラリ。図形表の大改造、月の道・真珠など他案。ムード・石・手紙・「響」の変更。Canvas2D での図形。

## 見た目・UX の要求
- デスクトップ: 図形は今の対称性・読みやすさを保ちつつ粒が滑らか。暗地、加算の細い白＋アクセント。
- スマホ 390×844: 図形が画面に成立し、文字とバーが明瞭。親指操作は不変。
- 初回タップの輪と音が 3 秒以内に返る体験は不変。

## デモモード
`?demo=1` で幽霊の指が打つだけで確認できる。probe 例: `[{"goto":"/?demo=1"},{"wait":600},{"clickAt":[1000,400]},{"wait":1200},{"shot":"high"},{"eval":"document.body.dataset.plate"}]` を desktop と mobile で。

## 作業役への注意
- 粒の見え方が全て。**必ず desktop/mobile の画像を自分で開き、拡大して粒が丸く連なっているか確認**してから REPORT を書く。見た目が改善していなければ未完了として正直に書く。
- 減衰は時間とともに消える仕様を壊さない（常時 rAF 禁止）。ビルド・コンソールエラー 0。次サイクルは normal。
