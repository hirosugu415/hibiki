# ORDER v15  (mode: normal)

## 目的
波が当たった石が、水に浮いているように「ゆっくり押されて滑る」ようにして、触れた→波→石が動く、という応答ループを体験として完成させる。

## 現状（司令塔の評価: 7/10、v14 コミット済み `93d332d`、ヘルス OK、warnings 空）
- 石は濡れた小石に読め、回折の証拠も撮れ、さざ波も出る。石の磨きは一区切り。
- 唯一の穴: 波が当たっても石は光る以外の反応をしない（`probe` で確認: さざ波・タップ後も `stone=0.500,0.600` のまま）。水に浮く説得力が最後の一歩で足りない。
- 既存の仕組み: `main.js` の `stone.tx/ty`（目標）へ `stone.x/y` が減速しながら追従する（約 104〜108 行）。`stoneEcho()` の setTimeout 内（波が石に届く瞬間、約 181〜189 行）が「到達」のフック。

## やること（優先順）
1. **波が石を押す。**
   - `stoneEcho()` の到達時点で、波源の反対方向へ `stone.tx/ty` を少しずらす（`clampStone` を通す）。押す量は、石から波源までの距離で減衰させる（近いほど大きい）。目安: 石のすぐ近くのタップで石の半径の約 0.5〜0.8 倍、画面の端近くからのタップは約 0.1〜0.2 倍。1 回の最大は石の半径の 1 倍まで。
   - 動きは既存の追従（イージング）をそのまま使い、**ゆっくり滑って止まる**（約 1.2〜2 秒）。急な跳ねや行き過ぎ（オーバーシュート）は禁止。
   - 石を掴んでいる間（`stone.grab`）は押さない。長押しの泉は波源になってよいが、連続で石が画面外へ飛ばないよう、1 回の到達ごとに上の上限を守り、`clampStone` で画面内（バー・ヒントに被らない範囲）に収める。
   - 石が動いている間だけ `wake()` で描画する（既存どおり。止まったら描画停止の既存ロジックを壊さない、常時 rAF は禁止）。
   - `dataset.stonePush`（押された回数）を追加。さざ波（`stoneLap`）は石を押さない（自分の波で動き続けるのを避ける）。
   - 受け入れ条件: `?live=1` で石の左（330,480 付近）をタップ→2.5 秒後、`dataset.stone` の x が右へ増えている（desktop で 0.500 → 0.51 以上）。石の右側をタップすると左へ動く。同じ場所を 5 回連打しても画面の外・バー・「響」に石が入り込まない。コンソールエラー 0。
2. **shots.json にその証拠を追加。** 既存の撮影は変えず、`stone-push` を 1 枚足す（`calm-after` の前後など、他の撮影を壊さない位置）。石の手前をタップ→ 3 秒待って撮影し、`eval` で `dataset.stone` を残す。`warnings` が空のまま。
   - 受け入れ条件: `desktop-stone-push.png` / `mobile-stone-push.png` で、石が中央（desktop-idle の位置）から目に見えてずれている。両幅で石が画面内に収まる。
3. **初回タップでヒントが即消える（小さな仕上げ）。** `mobile-touched.png` で輪が出ているのにヒント「触れてみてください」が残っている。初回の pointerdown で即座にフェード開始し、約 300ms 以内に見えなくなること。
   - 受け入れ条件: `mobile-touched.png` / `desktop-touched.png` でヒントが写らない。デモモードでは従来どおり（幽霊が動く間は出ていてよい）。

## やらないこと
- 石の複数化・消去・レンズ化、新規 GL パス・新規テクスチャ、物理定数（減衰・`uK`・解像度）の変更。
- バーのボタン追加・説明文の追加（UI は増やさない）。
- 石内部のさらなる質感変更（今回は触らない。優先度が低い）。
- Canvas2D フォールバックへの石の実装。

## 見た目・UX の要求
- 石の動きは水に浮いているように穏やかで、「気づいたら少し動いていた」程度。素早い・機械的・ゲーム的な動きにしない（Apple 的な静けさ）。
- デスクトップ 1280×800 / スマホ 390×844 の両方で、石が移動後もバー・ヒント・「響」と干渉しない。
- 石の掴み（半径+10px）とドラッグの慣性は現状維持。ドラッグ中の石の追従は変えない。
- 石が動いたあとも、既存の石の応答音・縁の光・回折が正しく動く（石の位置を `stone.x/y` から読んでいる前提を壊さない）。

## デモモード
`?demo=1` で幽霊の指が石を扱う既存挙動は維持する（幽霊のタップによる押しも許容。ただし幽霊の動きが破綻して石が端に張り付かないこと。必要なら demo では押す量を半分にしてよい）。ライブの確認は `?live=1`。カメラ・マイク不要。
