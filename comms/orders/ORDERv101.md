# ORDER v101  (mode: normal)
## 目的
案B「墨」を最小限で実装する: 水と同じ波を、和紙と墨の質感に写し替えるもう一つの世界を足す。既定の水は画素不変。
## やること
1. `uInk`(0..1) を最終色に追加。`?medium=ink` で固定オン（`dataset.medium="ink|water"`）。波高から墨濃度を作り、紙色(#efe9dd 付近)の地に、細い濃い縁＋ごく淡い内側の輪として描く。塗り円盤にしない。
   受け入れ: `?demo=1&seed=1&hour=13&medium=ink` の desktop/mobile で、輪が墨の輪郭として読め、水ホームとは別世界に見える。`medium=ink` なしの画面は現状と画素一致。
2. `uInk>0` のとき、石・星屑・金・底の光・鏡など既存の水専用効果を無効化または弱め、白地で破綻しない（白飛び・金の染み・暗い箱が出ない）。
   受け入れ: shots に `ink-ring`（初打後）、`ink-home`、`ink-off`（既定の水）。
3. 切り替え: 「響」タップが既存の操作（長押し等）と衝突しないか grep で確認し、衝突しなければ短押しで水⇄墨を 1.2 秒で遷移し localStorage 保存。衝突するなら URL 指定のみで止める（UI を増やさない）。
   受け入れ: 切替後の `dataset.medium` が変わる。音の release を墨で 0.5 倍（任意、重ければ省く）。
## やらないこと
カード/書き出し、新 UI、案A/C、底の光・vesselRing の調整、既存機能の変更。
## 見た目・UX の要求
desktop(1280×800)・mobile(390×844) とも墨は上品に。ピル・ワードマークは墨の世界でも読める色に（コントラスト確保）。ホームの静けさ維持。
## デモモード
`/?demo=1&seed=1&hour=13&medium=ink` と、対照の既定。shots.json に `ink-home` `ink-ring` `ink-off` を宣言。
## 作業役への注意
- 反転にしか見えない／白地で破綻して直せない場合は、実装を入れず（既定を壊さず）REPORT に撤退と書く。ヘルスを最優先。
- コンソールエラーを出さない。NOTES.md に要点を追記。
