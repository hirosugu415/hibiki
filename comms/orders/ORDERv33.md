# ORDER v33  (mode: normal)
## 目的
案C「初音」を実装し、初画面を「石が主役・砂は眠っている」状態にして、最初の 1 タップで波頭に乗って砂が目覚める体験を作る（8 点の壁の主因＝home で砂線が石より先に見える、を直す）。

## やること
1. **砂は眠って始まる（毎回の読み込み）**: 読み込み直後〜最初のタップ前は、砂線の輝度を現状（`SAND_SLEEP` 0.35 時の見た目）の約 1/5 以下にする（完全な 0 ではなく、ごく淡い気配は残してよい）。`wave-gl.js` の `awake` 下限（`SAND_SLEEP`）を uniform 化し、CPU 側の値 `sandSleep` で動かす。
   - 受け入れ条件: `/?demo=1` を 600ms 待った `desktop-home` / `mobile-home` で、砂線がほぼ見えず、石・ヒント文・バーが主役。画面が「空っぽ」に見えない（星屑・水の色の階層は残る）。`document.body.dataset.sandSleep` に現在の係数（0〜0.35）が出る。
2. **最初のタップで波頭に乗って目覚める**: 最初のタップ（デモでは幽霊の最初の打）以降、輪が到達した場所から順に砂が目覚める（既存の `env`（波の強さ）に連動する `awake` の上がり方を利用）。係数は最初の打の後 約 0.8 秒で 0.35 へ滑らかに上げる（段差・ちらつきなし）。
   - 受け入れ条件: `touched` 画像で、打点付近から外側へ砂が現れ、遠い所はまだ淡い。時間が経つと通常の c31 の見た目に落ち着く。
3. **無操作で静かに戻る**: 最後の入力から約 12 秒で `sandSleep` を 0.35 → 0.15 へゆっくり戻し、次のタップで再び目覚める（home に毎回戻らなくても、砂が主役になり続けない）。
   - 受け入れ条件: `?demo=1` を 20 秒放置した `idle` 画像で砂が home より静か。幽霊の指が打つと上がる。
4. **初音（初回限定の 3 音）**: localStorage `hatsune` が無い初回のみ、最初のタップで現在のスケールの根音・3 度・5 度を 0 / 0.18 / 0.36 秒ずれて鳴らす（`audio.js` の時刻指定で、`setTimeout` は使わない）。鳴らしたら `hatsune=1` を保存。デモ（`?demo=1`）は毎回初回扱い。`document.body.dataset.hatsune = "0|1"`。
   - 受け入れ条件: コード上 3 音がずれて鳴る。2 回目以降の通常タップは従来どおり 1 音で、音量・音色は変えない。

## やらないこと
- バーへの要素追加、文字・説明の追加、許可要求、ライブラリ追加、追加の全画面パス。
- 砂線の形・粒子の描き方の変更（縁のザラつきは今回は触らない）。
- 石・ムード・手紙・残響など他の層の変更。

## 見た目・UX の要求
- デスクトップ・スマホ（390×844）とも、初画面は「余白・石・一言・バー」の 4 階層。砂線の存在は気配程度。目覚めの変化は連続的で、白飛び・ちらつき・点滅なし。
- 目覚めた砂の明るさは現状（c31）を上限とし、超えない。

## デモモード
`?demo=1`。home 撮影（600ms 時点）は幽霊の最初の打より前であること。もし幽霊の最初の打が 600ms より前に起きるなら、最初の打を 1.5 秒以降に遅らせる（初画面の静けさを見せるため）。`shots.json` の既存画面名は変えず、必要なら `bloom`（最初の打の 500ms 後）を 1 つ追加してよい。

## 作業役への注意
- 失敗の再発防止: 砂の質感の微調整に時間を使わない。変えるのは係数のタイミングだけ。
- ビルド成功・コンソールエラー 0 を必ず確認。`app/NOTES.md` に `sandSleep` の状態遷移（眠る→目覚める→戻る）を 3 行で記録する。
- 規模が膨らんだら 4（初音）を後回しにして 1〜3 を確実に仕上げる。
