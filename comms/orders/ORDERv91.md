# ORDER v91  (mode: normal)
## 目的
底の光（caustic）を仕上げる: 輪以外の場所に出る金の染みを消し、金帯と青輪の間の灰色層をなくして、透明な金の光が輪の内側へ落ちて見えるようにする。このサイクルでこの項目は区切る。

## やること
1. **mobile 中央の染みの除去**（最優先）: `/?demo=1&seed=1&hour=13` mobile の caustic-ring で、輪の中央付近に金の羽根/炎状の縦長の染みが出ている。原因（clamp 応答の山形、打点中心の放射オフセット、または別波の干渉）を特定し、金が「現在の波頭の輪の近傍」以外に出ないようにする。
   受け入れ条件: mobile-caustic-ring で金の領域が輪に沿った帯だけ。中央・輪の外の孤立した金の塊が無い。desktop でも同様。
2. **灰色層の除去と内側への屈折**: 金帯と青輪の間の灰〜銀の層を無くす。金は青い線を横切らず、青線の内側（打点側）に接して落ちる。REPORT 申し送りの案（波の山/谷の符号で屈折方向を反転、または打点距離を使った半径方向の包絡）のうち実装が確実な方を選ぶ。追加パスは作らない。
   受け入れ条件: desktop-caustic-ring で、外から「青輪 → 金の帯」ではなく「金の帯が青輪の内側に沿う」順になり、中間に灰色の帯が無い。
3. **desktop 昼の彩度**: R−B を 55 以上（現状 39）に。金（琥珀寄り）に見え、オリーブ寄りに見えないこと。mobile は現状維持（78 前後）。夜は昼より赤いまま。最大チャネル 251 以下。
4. **維持**: dataset.caustic / ?caustic=0 / ?caustick / ?causw、shots.json の caustic-ring / caustic-off / caustic-night、ホーム放置時の静けさ（env=0 で分岐に入らない）。混み合った水面（demo 30s 後）でも塊や過剰なリボンにならないこと。

## やらないこと
UI追加、文字追加、波動 SIM 係数の変更、新しい操作、保存形式変更、殻・石・ムード・バー調整、2D フォールバック対応、他の演出の追加。

## 見た目・UX の要求
- desktop: 青い輪の内側に、柔らかい透明な金の光。ギラつかず上品。ワードマーク・石の影より暗い。
- mobile(390×844): 輪に沿った金の帯だけ。余計な染みなし。ホームは不変。
- 約2〜3秒で消える、60fps 近さ維持。

## デモモード
`/?demo=1&seed=1&hour=13` と `hour=20`、`?caustic=0` と並置。混雑確認は demo 30s 後。

## 作業役への注意
- 画像を自分で見て「染みが無いか」「灰色層が無いか」を確認し REPORT に一言書く。R−B 数値も desktop/mobile、昼/夜で記載。
- 内側への屈折が確実に実装できない場合は、灰色層の除去と染みの除去だけを優先し、未達を正直に書く。
- NOTES.md は4KB台、REPORT は事実のみ。ビルド成功・コンソールエラー0。
