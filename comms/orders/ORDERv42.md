# ORDER v42  (mode: normal)
## 目的
タップ後の画面に出る「画面を貫く直線の筋」の人工感を消し、同時に水面の残像を home と見比べなくても気づける程度に強める。

## やること
1. **直線の筋の正体を特定して直す**: c41 の `desktop-afterimage-washed`（石から斜め45度に上へ伸びる細く明るい直線）と `mobile-afterimage-washed`（輪の上を斜めに走る点線状の筋）が対象。`?demo=1&seed=1` で再現できる。原因（砂の節線 / 十字・放射線 / 夜光虫の流れ / 石の影）を `app/NOTES.md` に1行で記録する。
   - 方針: 完全な直線をやめる。弱い曲線にする（緩い湾曲と途中で消える減衰を入れる）か、画面を貫く長さを石から半径の範囲に収める。それでも人工的に見えるなら消してよい。
   - 受け入れ条件: seed=1 で、タップ 2.8 秒後の desktop・mobile のスクショに、端から端まで続く直線が無い。石・輪・バーの見え方は現状と同程度。
2. **残像を少しだけ強める**: 光の半径とムード色の明度を上げる。不透明度は 0.22 を超えない。ヒント・石・バー・「響」の可読性を落とさない。
   - 受け入れ条件: `afterimage-shown` と `home` を並べて見て、残像の有無がすぐ分かる。ただし汚れ・ゴミには見えず、水の奥の光に見える。保存なしの home は c41 と完全に同一。
3. `app/shots.json` は既存の `afterimage-shown` / `afterimage-washed` を使う。追加は不要。

## やらないこと
- 砂の強度・輝度・配置の全面見直し（1 の筋の対処に必要な最小限のみ）。バー・UI・文字の追加、ライブラリ追加、外部送信。
- 残像を主役にしない。手紙・器との機能重複を作らない。

## 見た目・UX の要求
- desktop・mobile 共通: 砂・筋は石の影として静かに見える。自然な水の中に人工的な直線を残さない。洗われるフェードは 2.5 秒前後のまま。

## デモモード
`?demo=1&seed=1` で再現。probe 例: `[{"goto":"/?demo=1&seed=1"},{"wait":600},{"shot":"s0"},{"clickAt":[820,420]},{"wait":2800},{"shot":"s1"},{"eval":"document.body.dataset.afterimage"}]`。カメラ・マイク不要。

## 作業役への注意
- 筋を消した結果、画面が寂しくなりすぎないか静止画で確認する。
- 1サイクルで終わる量に絞る。NOTES.md を更新し、REPORT に変更ファイルを列挙する。コンソールエラー 0 を厳守。
