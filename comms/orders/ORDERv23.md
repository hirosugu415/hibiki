# ORDER v23  (mode: normal)

## 目的
「響」が満ちた瞬間と押した瞬間に、**「響」の位置から水面全体へ静かな大きな輪が広がる**ようにして、30px の字に閉じ込められていた変化を 1 枚の静止画で見える体験にする。

## 背景
v22 評価 7/10（`comms/feedback/FEEDBACKv22.md`）。夜光虫のハローは消え、撮影も安定した。だが「響」の満ちは 4 倍に拡大しても青いにじみと微かな明るさしか見えず、1280px の全体画面ではほぼ判別できない。また `?demo=1` では「響」を押しても `letterShare='none'`（幽霊の打は手紙に記録されない）で、押す体験の証拠が撮れない。8 サイクル 7 点で横ばい。c24 は発想サイクル。今回は**小さく確実**に。

## やること（優先順）
1. **満ちた瞬間の輪（答え）。** `vesselShow()` で満ち切った瞬間（鈴を鳴らす箇所）に、「響」の中心座標（`#wordmark` の `getBoundingClientRect()` の中心を波場の座標へ変換）から、既存のタップと同じ仕組みで **1 つだけ大きめの輪**を水面に出す（振幅は通常タップの約 0.6、音は既存の鈴のみで、追加の音は足さない。手紙・`vessel` カウントには記録しない）。
   - 受け入れ条件: `?demo=1` で満ちた約 1 秒後の `desktop-vessel-full` / `mobile-vessel-full` に、左上の「響」付近を中心とした輪が見える。`document.body.dataset.vesselRing` が `1`（輪を出したら 1。リロードごとに 1 回）。
2. **満ちの色づきを強める。** 満ち切った「響」の字の内側が、1280px の全体画面でも `home` と見分けられるようにする（ムードのアクセント色を字に乗せ、明るさ・にじみを現状の約 1.5 倍に。字が読めなくなる白飛びは不可。字の位置・大きさ・フォントは不変）。
   - 受け入れ条件: `desktop-home` と `desktop-vessel-full` の左上 120×80px を並べて拡大したとき、字そのものの色（白→淡い青〜アクセント）の違いが明確に分かる。
3. **デモでも「響」を押せる。** `?demo=1` のとき、幽霊の打も手紙に記録する（デモ時のみ。通常操作の保存形式は変えない）。満ちた状態で `#wordmark` を押すと手紙が渡り（`letterShare` が `'1'` または `'fail'`＝クリップボード不可でも失敗ではなく状態が出る。`'none'` にはならない）、満ちが 0 に戻って、水面に**もう 1 つ輪**（押した瞬間、`dataset.vesselRing` は `2`）が出る。
   - 受け入れ条件: probe `[{"goto":"/?demo=1"},{"wait":6000},{"wait":6500},{"click":"#wordmark"},{"wait":900},{"shot":"pressed"},{"eval":"document.body.dataset.vessel+'|'+document.body.dataset.letterShare+'|'+document.body.dataset.vesselRing"}]` の結果が `0.000|1または fail|2`。
4. **撮影。** `app/shots.json` に `vessel-pressed`（上の probe と同じ手順、`wait` 合計は幅あたり 25 秒以下、`waitFor` を使うなら `body[data-vessel-call='1']` の 1 回だけ）を追加。既存画面は維持。healthy=true・step 警告 0 を保つ。

## やらないこと
- バー・ヒントへの新規 UI・文言・ボタン。GL シェーダー・状態テクスチャの変更。常時 rAF の追加。
- 手紙のフォーマット変更（デモ時にゴーストの打を記録するだけ）。外部通信・新規ライブラリ。`VISION.md`・`STATE.json`・`harness/` の編集。
- 夜光虫・石・砂州の再調整（今回は触らない）。

## 見た目・UX の要求
- desktop 1280×800 / mobile 390×844。輪は他の輪と同じ質感（滑らか・淡い）で、「通知」や「エフェクト」に見えない。バー・ヒントに重ならない。1 打目の体験（3 秒ルール）は不変。
- 輪が出ても `?demo=1` で 60 秒放置して例外が出ないこと。

## デモモード
- `?demo=1` で約 12 秒後に満ち、輪が 1 つ出る。押すと手紙が渡り輪がもう 1 つ。`dataset.vessel` / `vesselCall` / `vesselRing` / `letterShare` で確認。mobile は `--viewport mobile`。
