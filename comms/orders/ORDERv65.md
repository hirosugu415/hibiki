# ORDER v65  (mode: normal)
## 目的
輪の物理に分散（先走るさざ波）を入れ、1 タップの静止画で「ただ光る円」から「本物の水の波束」に見せる。IDEAS 案A の実装。

## やること
1. **sim に 4 次の分散項を追加**（wave-gl.js の更新式。無分散→弱い分散）。
   - 係数 0.004 から開始（`?disp=<係数>` で上書き可、`?disp=0` で従来式）。安定のため実効 uK を 0.47 → 0.40 前後へ下げ、主波の見かけの速さは変えない（速度を合わせる）。
   - 読み取りは追加の外側 4 点（または斜め 4 点）のみ。追加パス無し。mobile は fps を落とさないこと。
   - 受け入れ条件: desktop で `?demo=1&seed=1` の初打から 2.5s の画を `?disp=0` と既定で撮り、既定側だけ輪の外縁（または内側）に**細かい同心の列が 2 本以上**見える。拡大して比較できる shot を `shots.json` に追加（`disp-on` / `disp-off`、mobile も）。
2. **発散防止（必須）**: 最大振幅が閾値を超えたら係数を 0 にして復帰、または sim をリセットする検知を入れる。受け入れ条件: 連打・ドラッグ・長押し・雨・石・砂州を 30s 続けても発散・白飛びなし（打後 30s で輝度が ±3% 以内に静まる）、コンソールエラー 0。
3. **見た目の制約**: さざ波の振幅は主波の 25% 以下。筋・泡・染み・髪の毛に見せない（線は格子で自然に決まる幅、既存の縁ゲインを超えない）。無操作の home は `?disp=0` と平均輝度 ±1%・色同一。
4. `dataset.disp="係数,先行本数"`（CPU 推定で可）。`?disp=0` で `off`。NOTES.md に係数・安定の根拠・退路を記録。
5. 石・砂・雨輪・砂州で破綻が無いか各 1 枚確認（砂の節線位置が変わらないこと）。

## やらないこと
- 色・空・石の微調整、新しい UI・文字、新機能（案 B/C は対象外）。
- 2D フォールバックへの分散実装（無効でよい）。
- 主波の速度・音・音階・3 秒体験の変更。

## 見た目・UX の要求
- desktop・mobile とも home は不変で静か。タップ後の輪は現状より繊細で、水らしい構造を持つが、うるさくならない。

## デモモード
- `?demo=1&seed=1` の幽霊の初打で評価。比較は `?demo=1&seed=1&disp=0`。

## 作業役への注意
- 数値不安定が最大の罠。係数は小さく始め、見えなければ 0.006→0.008 と上げる前に安定を確認する。壊れたら係数 0 を既定にして退路を確保し、REPORT に明記する（壊れたアプリを出さない）。
- 静止画で差が見えない場合は、差が出る撮影タイミング（初打 1.5〜3s）と拡大 crop を shots に用意すること。
