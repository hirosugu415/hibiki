# ORDER v55  (mode: normal)
## 目的
c54 で残った小さな不整合（空の有無による輝度差・desktop 右上の非対称・音の LP 下限の矛盾）を、全体を動かさず局所で掃除する。

## やること
1. **空 on/off の輝度・色味を同一条件で比較（最優先・測定のみ→必要なら微修正）**: `/?demo=1&seed=1` を固定し、同じ経過時間で `?sky=0` と標準の平均輝度・平均 RGB を測る（desktop・mobile）。
   c54 の desktop-sky-off は sky-on より明るく緑がかって見えた。原因が撮影タイミングなら修正不要で NOTES に表を残す。空が色や輝度を動かしているなら、空の寄与だけを弱める。
   受け入れ条件: 同条件の平均輝度差が ±3% 以内、色相のずれが目視で分からない。結果を REPORT に数値で書く。
2. **desktop 右上の暗い base 勾配を局所で弱める**: `wave-gl.js` 108 行付近の base 暗化を、右上（画面右 30%・上 30%）だけ最大 +15% 持ち上げる程度にする（aspect 比が横長のときのみ）。全体の平均輝度は据え置き。
   受け入れ条件: desktop-home で右上が黒く沈まず、左上と同程度の深さの青に見える。mobile-home は変化なし。平均輝度は c54 比 ±3% 以内。
3. **奥行きの音の LP 下限を直す**: `audio.js` の LP を `max(base*(1−0.45·depth), min(base, 2000))` にして、下限が 2kHz を割る値を作らない（base が元から 2kHz 未満なら base のまま）。
   受け入れ条件: eval で下打ち・上打ち・中打ちの `dataset.depth` を出し、depth による LP 低下で 2kHz を割らない。音量差は −2dB 以内のまま。
4. NOTES.md を簡潔に更新。

## やらないこと
- 空の強度・うねりのさらなる強化、月・太陽・地平線。
- UI・文字の追加、新機能、新ノード。
- 全体の輝度を上げる変更。
- ファイル全体の書き直し（EOL 事故の再発防止。Edit ツールで局所編集のみ）。

## 見た目・UX の要求
- desktop・mobile とも home の静けさ（石・「触れてみてください」・ガラスのバー）を壊さない。右上を持ち上げても明るい靄・染みに見えてはならない。
- 音は誰が打っても心地よいまま。

## デモモード
- `/?demo=1&seed=1` と標準 shots.json で確認。`?sky=0` で比較。カメラ・マイク不要。
