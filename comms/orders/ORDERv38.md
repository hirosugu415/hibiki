# ORDER v38  (mode: normal)
## 目的
砂線と石の「重なり順」と「節の結び目」の粗を消し、石が常に最前面で砂は石の影として静かに寄り添う仕上がりにする。

## やること
1. 砂線を石の輪郭内でマスクする（wave-gl.js、砂の輝度計算部。石の SDF／既存の石シルエット判定を再利用）。
   - 石本体の内側では砂線の輝度を 0 に、輪郭の外 0〜6px で smoothstep により立ち上げる。
   - 受け入れ条件: `desktop-vessel-full` / `desktop-letter-play` / `desktop-sandfield-push` で、砂の輪が石の縁をまたいで石の上に乗らない。縁で線が自然に消える。
2. 節線の結び目（交差で光が溜まる hub）を抑える。
   - 砂の最終輝度に上限をかけるか、交差点の輝度加算を soft-clamp（例 `br = br/(1.0+br*k)`）で飽和させる。線の太さ・縁の質感（c30〜c35）は変えない。
   - 受け入れ条件: `mobile-sandfield-push` で石から離れた位置に光の塊が見えない。線は均一な細さで交差しても明るい点にならない。
3. mobile の砂場を少し見えやすくする。
   - mobile のみ halo 内の輝度係数を ×1.3 程度に上げる（desktop は不変）。
   - 受け入れ条件: `mobile-letter-play` / `mobile-sandfield-push` で石の周りに砂の輪がはっきり読める。それでも石が最も目立つ。home は砂なしで現状と同じ。
4. `document.body.dataset.sandHalo` は維持し、`app/shots.json` の既存ステップも維持。NOTES.md に c38 を 1〜2 行追記。

## やらないこと
- 新しい UI・文字・バーの要素追加、ライブラリ追加、砂の縁の質感の再調整、halo 範囲（外径・距離基準）の変更、全面パスの追加。

## 見た目・UX の要求
- home は現状どおり静かな 4 階層。砂は石の影のように静かで、白飛び・ちらつき・ゆらぎの破綻なし。デスクトップ・スマホ両方で破綻なし。

## デモモード
`?demo=1` の幽霊の指のみで確認。letter-play / vessel-full / sandfield-push の静止画で石の縁と結び目を見る。

## 作業役への注意
- 石の押し移動後もマスクが石に追従すること（uStoneC の更新を確認）。
- 砂が弱く見えすぎたら、マスクの立ち上がり幅を 6px → 3px、mobile 係数を ×1.5 へ。コンソールエラー 0・ビルド成功を最優先。
