# ORDER v95  (mode: normal)
## 目的
mobile に出る金の「楔・染み」（階段状のギザギザ）を確実に消し、底の光を輪の弧だけにする。

## やること
1. **mobile の孤立した金の染みを消す**。再現: `/?demo=1&seed=1&hour=13` を mobile で 5.5〜7.5s に撮ると、輪（右側）とは別に左上へ金の楔（縁が階段状）が出る。`app/src/wave-gl.js` の底の光（`cx`, `bgA/bgB`）で、`asp.x<0.8` のときだけ: (a) 輪の帯を狭める（rd/z 0.85〜1.15）、(b) 画面端 ~8% の内側へ向けて cx を fade、(c) cx を平滑化（曲率を広い半径でも平均する／しきい値で切って階段にならないよう smoothstep）。階段の原因は波テクスチャの格子と思われる。それでも孤立片が残るなら mobile の金強度を半分以下にしてよい。
   - 受け入れ条件: 5.0 / 5.5 / 6.0 / 7.0 / 9.5s の mobile 5 枚すべてで、輪から離れた金の塊・ギザギザ・階段が無い。金が出る場合は輪に沿った滑らかな細い弧のみ。
2. **desktop の金が「響」に被らない**ようにする（ワードマーク中心から ~110px 以内では金を最大 30% に）。desktop の他の領域は画素不変。
   - 受け入れ条件: `desktop-rebound-ring` で「響」の字が金に覆われず読める。
3. `mobile-rebound-ring/off` と probe を撮り、REPORT に「どの時刻で金が残ったか」を正直に書く。

## やらないこと
- 新UI・文字・案追加、波速変更、雫（rebound）の見た目変更、press-rebound の変更、底の光の大改修。

## 見た目・UX の要求
- desktop(1280×800): 金の輪は従来の質感を保つ（響の近傍のみ薄く）。
- mobile(390×844): 金は輪沿いの滑らかな弧のみ。ホーム放置画は不変。

## デモモード
`/?demo=1&seed=1&hour=13`、probe は `[{"goto":"/?demo=1&seed=1&hour=13"},{"wait":5000},{"shot":"a"},{"wait":500},{"shot":"b"},{"wait":500},{"shot":"c"},{"wait":1000},{"shot":"d"},{"wait":2500},{"shot":"e"}]` を `--viewport mobile` で。

## 作業役への注意
- 「滑らか」と書く前に、5 枚を自分の目で見て階段・塊が無いか確認する。前回 REPORT は証拠画像と食い違った。
- 局所修正に徹する。直らないなら強度を下げる方を選ぶ。
