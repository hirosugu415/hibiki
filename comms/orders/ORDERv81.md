# ORDER v81  (mode: normal)
## 目的
案A「潮の門」を実装する: 水面を横切る低い堤と1つの切れ目（門）を置き、タップした波が堤で割れ、門を抜けた波だけが反対側に半円として広がる（回折）様子を、静止画1枚で読めるようにする。
## やること
1. **堤と門（SIM の媒質）**: 縦画面は高さ約58%、desktop は中央やや右の位置に、水面を横切る帯状の「波を通さない領域」（高い減衰＋反射率 約0.5）を作る。帯の幅は画面短辺の 7% 以上、縁のない滑らかな山形。門の幅は短辺の約 14%、位置は約3分で画面幅の1割ゆっくり漂う。
   受け入れ条件: `/?demo=1&seed=1&hour=13` で堤の上側に1打 → 約1.5s 後の `gate-split` スクショで、堤の上は同心円、堤の下は門を中心にした半円が見える。`?gate=0` では従来どおり全面の円。
2. **見た目**: 堤は線を引かず、陰影（わずかな明暗）だけで見せる。輝度差は小さく、「筋・髪の毛」に見えないこと（c66 の教訓）。home の静止状態でも、堤は気づく程度に静かに存在し、文字・ボタンは増やさない。
   受け入れ条件: `desktop-home` / `mobile-home` で堤が石・「触れてみてください」・ピルと重ならず、全体が静か。
3. **音**: 門を抜けた輪が届いた瞬間に1音（stoneEcho の機構を門位置に流用）。
   受け入れ条件: `dataset.gate="堤y(0..1),門x(0..1),門幅"`（無効時 "off"、未発火は現在値）が出る。
4. **shots.json**: `gate-split`（上側1打の1.5s後）、`gate-off`（`?gate=0`）を desktop・mobile で追加。
## やらないこと
- 泉・bowl・石・雨・空の調整。UI ボタン・ラベル追加。案B・案C の先取り。
- 堤の上下で別の媒質（砂・板）を混ぜること。堤は1本、門は1つのみ。
## 見た目・UX の要求
- desktop: 半円が門から滑らかに出て、堤での反射で上側が荒れない。
- mobile 縦画面: 堤の下の空き領域が「門の向こう」として使われ、半円がはっきり見える。縞が忙しくならない。
- 1タップ目の輪と音は必ず先に返る（3秒体験を邪魔しない）。
## デモモード
`/?demo=1&seed=1&hour=13&gate=1`（demo では既定 on）。幽霊の最初の数打を堤の上側に置く。`?gate=0` と並置して確認。実装後に probe で堤が筋化しないかを必ず自分で確認すること。
## 作業役への注意
- 堤が筋・髪の毛に見える／上側が反射で荒れる場合は、幅を広げ、反射率と輝度差を下げる。それでも成立しなければ、無理に出さず `?gate=1` のオプトインに留めて REPORT に正直に書く。
- bowl の吸収帯・泉・雨・石と堤が重なる場合は堤を優先せず、発火を禁止する。
- コンソールエラー 0 とビルド成功を保つ。既存画面（home・bloom・springs・bowl）に回帰を出さない。
