# ORDER v31  (mode: normal)
## 目的
砂の線を「静かに眠り、波と音に応えて目覚める」ものにし、縁のギザつきを抑えて初画面の階層（ヒント・石が主役）を整える。

## やること
1. **縁を滑らかに**（`wave-gl.js` 砂ブロックの調整のみ）。現状は線の縁が鉛筆のかすれのようにギザつく。ノイズの閾値比較を `step` から `smoothstep(noise-0.12, noise+0.12, band)` 相当の柔らかい比較にし、ノイズの周波数を少し上げて（粒を小さく）、線の芯（d が小さい範囲）は抜けにくくする（芯は band の下駄を履かせる）。縁は粒でほどけるが、輪郭が揺れて見える凸凹は出さない。
   - 受け入れ条件: desktop-home の左の輪郭・drift-rest の斜線を 2x 切り出しして、「ガタつく線」でなく「芯が連続し、縁だけが細かくほどける線」に見える。色・輝度上限は不変。
2. **静止時は静かに、エネルギーで目覚める**。波の局所エネルギー（既存の h の絶対値や、近傍のなだらかな平均。uState の読み取りは画素あたり1回のまま）で砂線の明るさを ×0.45（静止）〜×1.0（波あり）に変える。波が去ると 2〜3 秒かけて静かな状態へ戻る（急に消えない）。
   - 受け入れ条件: desktop-home（無操作の初画面）で砂線が現在より明確に暗く、「触れてみてください」と石が目立つ。desktop-drift-early では輪が通る範囲の線が明るく、輪から離れた線は暗いまま（2枚を並べて差が肉眼で分かる）。drift-rest では再び静かな明るさに戻る。
3. **初画面の階層確認**。1・2 の後に desktop-home / mobile-home を自分で開き、ヒント文・石・ワードマーク・バー・砂線の順に目が行くか確認。まだ砂が勝つなら、静止時係数を 0.35 まで下げる（0.3 未満にはしない。線が消えると世界観が失われる）。
   - 受け入れ条件: 両 home で砂線が背景として読め、ヒント文が最初に目に入る。

## やらないこと
- 新 UI・文字・ボタン（バーは 4 個のまま）。石・砂州・夜光虫・手紙・ムード・音の変更。ライブラリ追加。輝度上限・色相の変更。粒を時間で動かすこと（固定ノイズのまま）。

## 見た目・UX の要求
- デスクトップ・スマホ（390×844）とも静けさ最優先。白飛び・ちらつき禁止。目覚めの明るさ変化は滑らか（フレーム間で段差が出ない）。タップ→音→輪の 3 秒体験は不変。

## デモモード
`?demo=1` の幽霊の指の打で確認。probe 例: `[{"goto":"/?demo=1"},{"wait":2500},{"clickAt":[820,420]},{"wait":350},{"shot":"drift-early"},{"wait":900},{"shot":"drift-late"},{"wait":4500},{"shot":"drift-rest"}]`。sandHold フックが砂の図形を保つ現行 shots.json をそのまま使ってよい。

## 作業役への注意
- 前回 REPORT の「畝の差」は静止画で判別できなかった。今回は「静止 vs 目覚め」という大きな差なので、early と rest を並べて差が見えなければ係数を上げてから報告する。見えなければ正直に書く。
- 砂ブロックの差し替えのみ。wave-gl.js を全面書き換えしない。コンソールエラー 0 を維持。
