# ORDER v31  (mode: normal)
## 目的
c30 で入った「追想」を**公式撮影の静止画で見えるようにし**、あわせて最初の 3 秒の「響」の階層（大きさ・細さ・字間・起動時の結像）を CSS だけで上質にして、6 点の帯から 7 点へ上げる材料（静止画の変化・タイポグラフィの質）を作る。シェーダーには触れない。

## やること（優先順）
1. **`app/shots.json` の整理（撮影の証拠を増やす）**。現状 4 画面（home / touched / echo / hold）のうち `echo` は `touched` とほぼ同じ絵なので **`echo` を `recall` に置き換える**。
   - `recall`: `url: "/?demo=1&recall=1"`、steps は `[{"wait": 3800}]` 程度（幽霊が 3 音→休符→追想 gen≥1 に入る時点）。**各画面の wait 合計は 4 秒以下**を守る。足りなければ `recall.js`/`ghost.js` の評価用休符（`recall=1` のときだけ）を詰めて 3.5 秒以内に追想 1 周目が写るよう調整してよい。
   - `touched` のクリック位置を、輪が端で切れない位置に変える（例: desktop でも mobile でも画面内に収まる `[420, 360]` 付近。両ビューポートで共通座標なので 390×844 でも画面内であること）。
   - 受け入れ条件: `node harness/tools/probe.mjs` 相当の撮影で 8 枚すべて blank=false・コンソールエラー 0。`desktop-recall.png` / `mobile-recall.png` に、幽霊の指の輪と**別の位置**の弱い輪が見える。eval で `dataset.recallGen ≥ 1`。
2. **「響」ワードマークの階層を上質に（CSS 中心、`style.css` の `#wordmark` と必要なら `#hint`）**。
   - デスクトップ 40px・スマホ 34px 前後、font-weight 200〜300、字間を広めに（0.12〜0.18em）、不透明度は 0.85 前後。位置・タップ領域（既存の `::before` の拡張）・`role=button`（手紙の機能）は維持。
   - 起動時に約 1.6 秒の CSS アニメーション 1 本で**ぼかし 3px・不透明度 0.5 から、くっきり**へ結像（`@keyframes` のみ。JS・rAF・GL の追加は無し）。**途中の瞬間に撮られても破綻しない**（ぼかしは 3px 以下、不透明度は 0.5 未満にしない）。`prefers-reduced-motion` ではアニメーション無し。
   - 受け入れ条件: `desktop-home.png` / `mobile-home.png` で「響」が c30 より明確に大きく細く見え、ヒント「触れてみてください」と重ならず、下部ピルとも余白が崩れない。スマホ幅 390 で左端の余白が 24px 以上。
3. **`desktop-touched` / `mobile-touched` の輪の見え方の確認**（変更は shots.json の座標だけで済めばそれでよい）。
   - 受け入れ条件: touched の画像で、輪が画面内にほぼ収まり、触れた位置が輪の中心として読み取れる。

## やらないこと
- UI（ボタン・文言・アイコン）の追加、`wave-gl.js` の変更、追加の rAF、ライブラリ追加、新しい視覚要素（`echoRing` 相当）。
- 追想の仕様変更（6 秒・3 周・音量比）、`recall=1` / `recall=0` パラメータの削除、通常の `?demo=1` の幽霊の台本の変更。
- 雫の演出・光の帯・夜光虫（案B/C の本体）。`shots.json` の画面数を増やすこと（5 画面にしない、置き換えのみ）。
- `harness/`・`comms/STATE.json`・`comms/LOG.md`・`comms/VISION.md`・ルートの package 系・`.gitignore` の編集。

## 見た目・UX の要求
- デスクトップ 1280×800: 左上の「響」が静かに存在感を持つ（小さな装飾でなくブランドの署名に見える）。他の要素（石・ピル・ヒント）の位置と色は c30 のまま。
- スマホ 390×844: 「響」がステータス領域・安全域にかからず、ピルと同じ左右の整列感を保つ。
- 3 秒ルール（1 タップで輪＋音）は不変。追想は静止後のみ。

## デモモード
- `?demo=1`（通常）と `?demo=1&recall=1`（追想評価、shots.json に載る）。カメラ・マイク不要。

## 作業役への注意
- 撮影の起動失敗が続くと自動 rollback で成果を失う（c22・c27・c28・c29）。変更は `shots.json` と `style.css` 中心の小さな差分に収める。**終わったら自分で `npm run build` と probe（desktop・mobile）を実行し、起動したプロセスは全て終了させる。**
- 追想の評価用休符を調整する場合は `recall=1` のときだけに限定し、通常デモに影響させない。
- REPORT には build 結果、probe の dataset 値、各画像で確認した事実を書く。コミットに Claude を貢献者として入れない。
