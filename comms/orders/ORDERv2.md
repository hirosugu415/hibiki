# ORDER v2  (mode: normal)

## 目的
水面を「針金の網目」から「静かで深い水」へ磨き直し、触れた瞬間の光と音高を結びつけて、Apple 水準の静けさと階層を作る。

## やること（優先順位順）
1. **減衰と階層（最優先）**: 波の減衰を強め、何度触れても画面が線で埋まらないようにする。
   - 新しい波は明るく、少し太く。古い波は急速に淡くなる。静かな状態に戻るまで目安 4〜6 秒。
   - ドラッグは1本の連続した筋（細かな連続波源）とし、髪の毛状の網目にしない。注入量は速度で抑え、同時波源も間引く。
   - 受け入れ条件: `?demo=1` で 10 秒放置した `home` スクショに、同心円が重なり合った網目状の線が残らない。暗い空白が見える状態で、明るい輪が1〜3個だけ見える。
     通常モードで 5 回タップ→6 秒待機すると、ほぼ静かな水面に戻る。ドラッグ直後のスクショが線の網目にならない。
2. **暁ムードの再設計**: 琥珀〜桃の明るく暖かい色にする。現状のワイン色は却下。
   - `deep`/`mid`/`accent` を再設計する。上部は深い茜、下部は桃〜琥珀の淡い光とし、ハイライトは明るい琥珀色にする。
   - 3 ムードで水面の質感も変える。例: 凪＝屈折強め・澄む、夜＝屈折弱め・光の尾が長い、暁＝リム光が暖かく広い。
   - 受け入れ条件: `mood-dawn` を撮ったとき、暁と一目で分かる暖色で、波紋の輪がはっきり見える。凪・夜・暁の3枚が明確に違う印象になる。
3. **触れた瞬間の光と音高の可視化**: pointerdown の位置に、短い柔らかなフラッシュ（光の滲み）を出す。色相は音高に応じてアクセント色の周りでわずかに変える（高い音ほど明るく少し白寄り）。
   - フラッシュは約 400ms で消える。白飛び禁止。
   - 受け入れ条件: `touched` スクショで、触れた位置が即座に分かる光点がある。左端と右端でタップしたときに、色味・明るさに差がある。
4. **ヒントの視認性**: 「触れてみてください」のコントラストを上げ、ゆっくり呼吸するように明滅（透明度のみ）させる。最初のタッチでフェードアウトする挙動は維持する。
   - 受け入れ条件: 青背景（凪・暁）で文字が明瞭に読める。ただし主張しすぎない（太字にしない）。
5. **shots.json**: 現状の `home`/`touched`/`mood-night` に、`mood-dawn` を追加する。加えて、`?demo=1` で `wait 9000` 後に撮る `calm-after` を追加する（減衰の確認用）。

## やらないこと
- 録音・ループ、共有・書き出し、マイク/カメラ/傾きセンサー、設定画面、新しいムードの追加、UI ボタンの追加。
- 外部ライブラリ、ネットワーク、CDN。
- 波動方程式そのものの変更（減衰、注入量、見た目のシェーダー調整に留める）。

## 見た目・UX の要求
- デスクトップ(1280×800)とスマホ(390×844)の両方で、ガラスバー・「響」・ヒントの位置は現状から変えない。
- 波の見た目: 細い針金ではなく、やわらかい太さを持つ光の輪にする。白飛び・ジャギー・ちらつきは禁止。
- UI の状態遷移は 200–400ms の ease-out（`cubic-bezier(.2,.8,.2,1)`）を維持する。
- 音は変えなくてよい。ただしドラッグ時の発音が過密にならないよう、現状のスロットルは維持する。

## デモモード
`?demo=1` で確認する。幽霊の指が演奏するので、`calm-after` で静かな水面に戻っていることを必ずスクショで確認すること。
幽霊の演奏頻度が高すぎて網目になるなら、間隔を広げて構わない。

## 作業役への注意
- 前回（v1）は新しい輪がとても綺麗だった。その質は落とさず、古い波のノイズを消す方向で調整する。減衰を上げ過ぎて輪が見えなくなるのは本末転倒。
- 完了前に `node harness/tools/probe.mjs` でデスクトップ・スマホ両方を実際に操作し、スクショを自分の目で確認する。連打・ドラッグ・ムード切替も試す。
- 触っていない主張を REPORT に書かない。聞いていない音について「良い音」と書かない。
- ビルド失敗・コンソールエラーは即 repair になる。コミットに Claude を貢献者として入れない。
