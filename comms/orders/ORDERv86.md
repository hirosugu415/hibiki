# ORDER v86  (mode: normal)
## 目的
巻貝を「線画の図面」から「真珠層のガラス質」へ磨き、石との重なりと水底の図鑑感を解消して、Apple 的な質感に引き上げる。
## やること
1. **貝殻の質感（最優先, shell.js）**: 部屋ごとに淡い真珠色の放射/線形グラデ塗り（部屋ごとに色相をわずかにずらす。ムードに馴染む）、外縁は太め(3〜4px)の外線に内側の細いハイライト線、隔壁は細く(1〜1.5px)低コントラストにする。輪郭を隠す減光はしない。
   - 受け入れ条件: `/?demo=1&seed=1&hour=13&shell=show` の desktop・mobile `shell-show` で、部屋の分割が従来どおり読めつつ、均一な白線の図面ではなく厚み・光沢のある殻に見える（部屋ごとの濃淡差が目視できる）。`dataset.shell` の値は不変（"12,2.8"）、`?shell=0` は "off" で画素一致。
2. **構図（石・残像との重なり）**: 発火時の中心を石の領域（上端/影）から避け、石の上方に収める（mobile で殻が石に触れない）。自然発火時（show 以外）は発火直前〜表示中、残像リング・ゴースト輪を弱める（既存の afterimage 系の opacity を一時的に下げるだけ。挙動は変えない）。
   - 受け入れ条件: shell-show で殻の下端と石の上端の間に隙間があり、影が殻を透けない。`?seed=1&hour=13` で9打→約11秒放置の probe 画面（desktop）で、殻周囲に波紋リングが騒がしく重ならない。
3. **水底の貝殻の多様化と減光**: 5個の大きさ(0.6〜1.3倍)・向き(回転)・巻き数を明確に変え、輪郭輝度は現状の約65%に下げる（ホームの静けさ優先。ただし形は読める）。
   - 受け入れ条件: `?shells=5` の desktop・mobile `shells-floor` で、5個が大きさ・向きとも一目で異なり、波紋より目立たない。既定（0個）は画素一致。`dataset.shells="5"`。
## やらないこと
PNG保存、新しい常設UI・文字、潮の門など撤退済み機能、貝殻の表示トリガー/保存形式の変更、ワードマーク・バーの挙動変更、外部通信。
## 見た目・UX の要求
- desktop・mobile とも貝殻は中央に収まりバー・一言と重ならない。ガラス質で光沢があり、縁は柔らかく、ホーム（打つ前）は c85 と画素一致。
- 質感は Canvas2D のグラデ/合成のみ。重くしない（貝殻表示中も体感60fps）。
## デモモード
`/?demo=1&seed=1&hour=13&shell=show`、`&shells=5`。shots.json の `shell-show` `shells-floor` は据え置き。
## 作業役への注意
- 質感を出すために塗り円盤・髪の毛状の細線に戻さないこと。輪郭の読みやすさは c85 以上を維持。
- 変更は shell.js 中心。main.js は構図（中心位置・残像の一時減光）の最小変更のみ。NOTES.md は4KB台を維持、REPORT は事実のみ。
