# ORDER v25  (mode: normal)
## 目的
案A「砂の図形（Chladni）」を実装し、**1 回触れただけで画面全体に音高が決める幾何学模様が現れる**絵にして、7 点の壁を破る。

## やること（優先順）
1. **クラドニ図形（RENDER に解析式＋`uniform vec4 uChl`＝n, m, 量, 位相）**。IDEAS.md の「Cycle 24 案A」の設計に従う。
   - 板の式 `f = cos(nπX)cos(mπY) − cos(mπX)cos(nπY)`（X,Y は短辺基準 0–1）。粒は 3px セルの hash で、`|f|` が小さいほど残る。量 0→1 で散らばり→節の線に収束。追加パス・追加テクスチャ読み取りは作らない。
   - 受け入れ条件: `?demo=1` で最初の打の約 1.1 秒後、**1280px 全体に砂粒でできた対称な線画**が見え、輪の上にも重なる（desktop-touched 相当の静止画で、画面の 6 割以上に線が見える）。輪は消えない。
2. **音高→(n,m)**: 横位置の度数ごとに固定表で決める。左は粗く大きい図形、右は細かい図形。隣り合う度数で必ず見た目が変わる組にする。切替は 0.5 秒以上あける。
   - 受け入れ条件: x=300 と x=1000 の 2 枚で図形が明確に違う（線の本数が異なる）。`document.body.dataset.plate = "n,m,量"`、`dataset.plateFig`（切替累計）。量は 1 打後 1 秒で 0.6 以上。
3. **ほどけ方**: 約 6 秒で量が減衰して消える。減衰中のみ `wake()`、0 になれば uniform を 0 にして素通り（常時 rAF 禁止）。長押しの泉の間は図形を保ち、離すとほどける。
4. **砂の粒音**（`audio.js`、既存ノイズ源、図形が組み上がる 0.4 秒だけ・極小音量）。
5. `app/shots.json` に `plate-low`（x=300）と `plate-high`（x=1000）を足す（wait 合計は幅あたり 25 秒以下）。`app/NOTES.md` を更新。

## やらないこと
- バーのボタン追加、新 UI、新ライブラリ。月の道・真珠など他案。「響」の字・手紙・ムード・石・砂州の変更。Canvas2D フォールバックでの図形（音と輪のみで可）。

## 見た目・UX の要求
- 粒は 2px（CSS px 基準）、白とアクセント色の混合、**輝度上限 0.35 以上 0.5 以下で、静止画でも線が読める強さ**。散らばり段階は 0.05 以下。節の線幅は短辺の約 1.2%。全面の砂嵐・白飛び・雪に見える散布は不合格。暗地のまま、加算の細い白。
- スマホ幅（390×844）: 同じ図形が画面内で成立し、バー・ヒント・「響」の可読性を損なわない。バー周辺は少し抑えてよい。
- 初回タップの輪と音が 3 秒以内に返る体験は不変。

## デモモード
幽霊の指の最初の打（`tap()` 経由）で台本の追加なしに出る。probe 例: `[{"goto":"/?demo=1"},{"wait":600},{"clickAt":[300,400]},{"wait":1100},{"shot":"low"},{"eval":"document.body.dataset.plate"},{"wait":3500},{"clickAt":[1000,400]},{"wait":1100},{"shot":"high"},{"eval":"document.body.dataset.plate"}]`

## 作業役への注意
- 最大リスクは「砂が雪・ノイズに見える」こと。**必ず自分で probe して `low`/`high` を目で確認**し、線が見えなければ粒密度と線幅を詰めてから REPORT を書く。見えない図形は 0 点扱い（c23 の隅の輪と同じ失敗）。
- ビルドとコンソールエラー 0 を確認。次サイクルは normal（壊したら repair）。
