# ORDER v54  (mode: normal)
## 目的
c53 の「空の映り込み」を、輪が通ったときに目で分かる水準へ局所的に引き上げ、あわせて音に最小の奥行き（打つ高さで遠近）を足す。

## やること
1. **main.js の改行コード修復（最優先・小）**: c53 で main.js が全行入れ替わっている（`git diff --stat` は 1919 行、`--ignore-space-at-eol` では差分ゼロ ＝ EOL のみ変更）。`git show HEAD:app/src/main.js` と同じ EOL に戻し、`git diff --stat` で main.js の差分が実変更分だけになること。
   受け入れ条件: diff.stat の main.js が数十行以内（今回 main.js を触らなければ 0）。以後 Edit ツール以外で全ファイルを書き直さない。
2. **空の映り込みを局所で見えるものに**: `wave-gl.js` の法線 y の項（±0.12 クランプ）を上げる（目安 ±0.25）、または輪が通る帯でのみ空の勾配位相を動かす。全体は据え置き。
   受け入れ条件: `sky-top-tap`（desktop・mobile）で、輪が通る上端付近の空の縁がうねって見え、`?sky=0` と並べて違いが分かる。`sky-on` の home は静かなまま。平均輝度は c53 と同様に表で ±3% 以内（空の寄与のみ）。
3. **desktop 凪の上端の暗い縁（vignette）と空の干渉を和らげる**: 上端 40px 付近が暗縁と空に挟まれ帯に見える点を、vignette の上端側だけ弱める、または空の立ち上がりを滑らかにして解消。
   受け入れ条件: desktop-home / sky-on の上端が「暗→明→暗」の帯にならず、滑らかな一方向の勾配に見える。
4. **奥行きの音（最小版）**: `voice()` に `depth`（0=手前/画面下, 1=奥/画面上）を渡し、(a) ローパス周波数 ×(1−0.45·depth)（下限 2kHz）、(b) 既存リバーブ send を depth で +40% まで、(c) 音量は −2dB 以内。石の影判定・新ノードは作らない。`dataset.depth="d,wet,lp"`（最後の音の値）を設定。
   受け入れ条件: 手前打と奥打で dataset が数値差を示し（例 `0.1,…,7000` と `0.9,…,≈3500`）、音量の極端な差が無い。幽霊の指が両方を打つこと。
5. NOTES.md 更新（簡潔に）。

## やらないこと
- 月・太陽の円盤、直線の地平線、UI・文字の追加、石の影による音のこもり、他機能の調整。
- GL 失敗時（Canvas2D）の空対応。
- 全体の輝度を上げる変更（c51 の再燃防止）。

## 見た目・UX の要求
- desktop・mobile とも home の静けさ（石・「触れてみてください」・ガラスのバー）を壊さない。空は映り込みであり、帯・筋・明るい靄に見えてはならない。
- 音は誰が打っても心地よいまま。上を打って「弱い・濁る」と感じさせない（ローパス下限 2kHz、音量差 −2dB 以内）。

## デモモード
- `/?demo=1&seed=1` と標準 shots.json で確認。`?sky=0` で比較。`dataset.depth` は eval で読む。カメラ・マイク不要。
