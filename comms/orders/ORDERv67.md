# ORDER v67  (mode: normal)
## 目的
触れる前から水面が「生きている」と伝わるよう、デスクトップのホバーに水面がかすかに応える「近づく指」を入れる。

## やること
1. **近づく指（ホバー応答）**（必須）。マウスが水面上で押さずに動いているとき、カーソル位置に、ごく弱い光の凹み（縁なし・低コントラストの柔らかい滑らかな窪み＋ほのかな明るさ）を出し、なめらかに追従させる。静止すると数秒でゆっくり消える。
   - 受け入れ条件: probe で `{"hover":...}` を水面に当てて wait 後に shot → カーソル位置に気づける程度の柔らかい変化があり、塗り円盤・強い発光（泡）・直線（筋）に見えない。タップすると従来どおりの輪と音が出る（ホバー表現がタップを邪魔しない）。ホバーでは音は鳴らさない。
   - 受け入れ条件: タッチ端末（`pointerType==='touch'`）では一切出ない。mobile の home・touched は不変。マウスが無い・動かない home は ±1% 以内で不変。
   - 実装は既存の描画パス内で完結（GL の追加パス・テクスチャ読み取り禁止）。sim に毎フレーム負 splat を入れない（輪になる）。描画側の uniform（位置・強さ）で軽く表現するのが安全。`?hover=0` で無効化できる。`dataset.hover` に on/off を出す。
2. **撮影の整備**。shots.json に `hover-near`（水面の中ほどにホバーして ~600ms 後）を追加。さらに disp-on / hf-off の比較が空振りしている問題を直し、輪が見えるタイミング（タップ直後 ~700ms）で撮る。
   - 受け入れ条件: disp-on / hf-off に輪が写っている。撮影 wait 合計は幅あたり 25s 以下。
3. NOTES.md に 1 節だけ追記し 4KB 以内を保つ。

## やらないこと
- 分散・高周波・sim 解像度・石・空・色の調整。音・音階の変更。新しい UI・文字。
- ホバーでの発音、カーソルの置き換え（`cursor` 非表示など）。

## 見た目・UX の要求
- desktop: ホバーは「気づけば分かる」程度。うるさくしない。バー上では出さない。
- mobile: 変化なし。home は不変で静か。

## デモモード
- `?demo=1&seed=1` でも通常どおり。ホバーの確認は probe の hover step（非デモ URL でも可）。ゴーストの指とホバーが同時に出ても破綻しないこと。

## 作業役への注意
- 「泡・筋・髪の毛」で過去に減点された。縁を作らず低コントラストに。効果が弱すぎる場合のみ係数を少し上げる。壊れたら既定オフにして REPORT に明記。
- 小さく確実に。コンソールエラー 0 を最優先。
