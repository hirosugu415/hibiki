# ORDER v47  (mode: normal)
## 目的
石の周りに残る砂の線を「時間で必ず消える」構造にし、ワードマークの発光を静かに保つ。

## やること
1. **砂の線の寿命**（wave-gl.js の砂/石の線の描画）: 石が動いている間のみ線が出て、石が止まってから約 2.5 秒で強度が確実に 0 になる（線形でなく ease-out でフェード）。動作中の最大強度も現状の約 60% に下げる。係数調整ではなく「止まった経過時間による乗算ゲート」で実装。
   受け入れ条件: 石を押した 4 秒後（desktop・mobile）のスクショに、石の周りの曲線がほぼ見えない。押している最中（sandfield-push）は薄い影として読める。home は不変。
2. **ワードマーク発光**: 「響」の青い発光（ready 状態）を、home 表示時と同じ通常見え方に寄せる。発光は学習の呼吸（#wordmark.learn）中と cycle 中のみ淡く出し、終了後 2 秒で通常へ。
   受け入れ条件: desktop-loop-end / mobile-home / desktop-home で「響」が同じ色・同じ明るさ。
3. **人手ばらつき probe**: 同じ4打フレーズを 位置 ±0.05・間隔 ±30% で2度打つケースを2パターン probe し、cycle に入るか REPORT に記録。偽陽性3種（2打×2、同点3連打×2、別位置フレーズ）が off のままであることも再確認。

## やらないこと
- UI 文字・ボタン追加、新機能、ライブラリ追加、残像・バー・学習許容の変更（3 の結果が悪くても今回は許容を触らず報告のみ）。

## 見た目・UX の要求
- desktop・mobile とも home の静けさと 3 秒以内の最初の一打を不変に。新しい視覚要素を足さない（消す方向のみ）。

## デモモード
- `/?demo=1&seed=1` で loop が off→learned→cycle→off。既存 shots.json の項目を維持。

## 作業役への注意
- 線を消しすぎて石が無地の影に見えなくなったら、最大強度のみ戻す（寿命ゲートは維持）。
- NOTES.md の砂の仕様を更新。コンソールエラー0を維持。
