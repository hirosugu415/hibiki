# ORDER v71  (mode: normal)
## 目的
指で「ほぼ閉じた輪」を描くと、輪の内側へ波が収束し中心で一点に立ち上がる（案B: Gathering Ring）を、誤検出なく・UI ゼロで入れる。水底は凍結。
## やること
1. **閉じ判定**（既存の drag の位置列を利用）: 始終点距離 < 周長の 12%、囲む面積 > 画面短辺²の 3%、周長を 1.5s 以内に描いた時のみ成立。成立後 2s クールダウン。普通の短いドラッグ・往復・直線では絶対に発火しない。
   受け入れ条件: eval で、(a) 円軌跡 → `dataset.gather` の回数が +1、(b) 直線・S 字・小さな円（面積不足）・ゆっくり円（1.5s 超）では +1 されない、を REPORT に表で載せる。
2. **収束演出**: 成立時、軌跡の各点付近から出た波が内向きに集まり、輪の速さ r/c の後に中心に追加 splat（通常の打より少し大きい程度）で一点が立ち上がる。音は 2〜3 音の和音（既存 voice、音量は通常の打と同等以下）。光は広く低コントラスト、白飛びしない。
   受け入れ条件: 円ドラッグ直後と収束+100ms の 2 枚で、輪が外でなく内側へ縮み、中心に 1 つの明るい集中が見える。`?gather=0` では中心に何も立たない。
3. **デモ再現**: ghost.js の MOTIFS に円モチーフを 1 つ追加し、`?demo=1&seed=1` で再現する。shots.json に `gather-draw` / `gather-focus`（固定座標の clickAt/drag、desktop・mobile）を追加。
   受け入れ条件: mobile でも小さすぎない円（半径 ≥ 画面短辺×0.15）で成立し、親指操作で届く。
4. `dataset.gather="回数,中心x,中心y,収束ms"` を出し、NOTES.md に判定式・退路（`?gather=0`）を記載。
## やらないこと
- 水底・色・空・石・分散・高周波の変更、UI やラベルの追加、新入力、音色変更。
- 閉じていない軌跡への演出。判定のしきい値を緩めること（誤検出より未検出を選ぶ）。
## 見た目・UX の要求
- home は現状と同じ静けさ。通常のタップ・ドラッグの感触は不変。収束の光は筋・泡・髪の毛に見えない柔らかさ。desktop・mobile の両方で円が描け、収束が見える。
## デモモード
`?demo=1&seed=1` の幽霊が円を描き、`dataset.gather` が増えること。eval で取得。
## 作業役への注意
- 「やった」と言う前に、gather-draw / gather-focus を自分で開き、内向き収束と中心の集中が見えるかを所見に書く。見えなければ強さを調整。
- 誤検出テスト（直線・S字・小円・遅い円）を必ず実行して表にする。コンソールエラー 0。NOTES.md 更新。
