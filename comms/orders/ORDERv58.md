# ORDER v58  (mode: normal)
## 目的
刻の水の「見える差」を美しく直す。夕の上端を濁った灰茶から透き通る琥珀へ、朝を昼と区別できる淡い水色へ、夜を深い藍へ。新機能は足さない。

## やること
1. **夕の濁りを解消**（`app/src/moods.js` の `HOUR_KEYS`、h:19）。
   - 青を潰す乗算（B×0.35）をやめる。B の乗算は 0.75〜0.85 を保ち、R/G の加算（合計上限 0.08 内）で琥珀〜薔薇色に寄せる。
   - 受け入れ条件: `?demo=1&seed=1&hour=19` の desktop-hour-evening で上端が「灰茶」ではなく暖かい琥珀に見える。上端 12% 平均で R > B かつ彩度が c57（33,40,48）より明確に高い（R−B ≥ 12、かつ G が R より低い）。帯の下端に線が見えない。mobile も同様。
2. **朝の差を可視化**（h:6）。主に乗算で上端を淡く明るい水色〜青灰に。
   - 受け入れ条件: hour=6 と hour=13 の上端 12% 平均 RGB の差が合計 ΔRGB ≥ 15。hour=6 の中央〜下（40–90%）輝度は hour=13 と ±3% 以内。
3. **夜の差を可視化**（h:1）。上端が一段暗い藍になる。
   - 受け入れ条件: hour=1 は hour=13 より上端 12% の輝度が 10% 以上低く、色相は青のまま（灰にならない）。
4. **連続性の確認**: `?hour=0..23` を 1 時間刻みで上端 12% 平均 RGB を測り、REPORT に表（24 行でなく 8 時点でよい: 0,3,6,9,13,16,19,22）で載せる。隣り合う時点で段差・色のジャンプがないこと（hourTint の補間が連続であること）。
5. NOTES.md に新しい値を追記。`app/shots.json` は変更不要（hour 固定済み）。

## やらないこと
- 新UI・文字・ボタン。残響・音階の係数変更。ムード追加。新しいパス。
- 中央〜下の背景を明るくすること（加算上限 0.08、輝度 ±3% は維持）。
- 外部通信・位置情報・天気 API。

## 見た目・UX の要求
- desktop: 夕は上端にだけ琥珀がにじむ。朝は冷たく淡い。夜は深い。どれも静かで、色が濁らない。
- mobile: 上端 20% の帯がなだらか。線や色のバンディングが出ない。
- hour=13 の home は c57 と同一（回帰ゼロ）。3 秒体験は不変。

## デモモード
`?demo=1&seed=1&hour=6` / `19` / `1` / `13` で確認。

## 作業役への注意
- 夜ムード × 夜の時刻など重なる場合も、合計上限（上端 +8%、輝度 ±3%）を守る。
- 夕の確認は必ず desktop-hour-evening を目で見る。数値だけで「琥珀」と判断しない（c57 は数値上 R が高くても灰茶に見えた）。
- 差が識別できなければ失敗。上端 20% を hour=6/13/19/1 で並べたスクショと数値を REPORT に示す。
