# ORDER v88  (mode: innovation)
## 目的
殻の再生を静かに整える最小修正を行ったうえで、「静止画1枚で別物と読める」新しい体験案を3つ IDEAS.md に出す（新機能の実装はしない）。
## やること
1. **殻再生の鎮静（小修正のみ, shell.js 内）**: 殻の再生で出る波紋を弱く小さくする。(a) 再生の打は最大8打（古い順に等間隔で間引く）、間隔は約0.4秒のまま。(b) 波紋の振幅・半径は通常 tap の半分程度、(c) 再生の x,y は画面端の 12% 内側に clamp する。
   受け入れ条件: `/?demo=1&seed=1&hour=13&shells=5` で殻0をクリック→`dataset.shellPlay` が "0,8" 以下の打数、再生後 "off"。desktop・mobile の `shell-play` で波紋が画面端に出ず、c87 より明らかに小さく淡い。`?shell=show` の dataset.shell と既定ホームは不変。ビルド成功・コンソールエラー0。
2. **発想**: `comms/IDEAS.md` の末尾に `## Cycle 88 — 提案 (builder)` を追記し、案A/B/C を書く。各案: 体験（誰が何をして何が起きるか）／静止画での差（スクショ1枚で伝わるか）／規模（S/M）／デモでの確認方法（URL・dataset）／退路／最大リスク。最後に「作業役の推し」を1つ。
   領域（3案は互いに別領域）:
   - 領域X: **入力の側**。指1本のタップ以外（複数指、ドラッグの質、キーボード、傾き、マイク）で演奏の表現が広がる案。デモ（カメラ・マイク無し）でも幽霊の指や URL パラメータで確認できること。
   - 領域Y: **水面そのものの質感**。Apple 的な洗練として、光・屈折・奥行き・縁の仕上げを一段上げる案。静止画1枚で現状との差が読めること（低コントラストの微細効果は却下対象）。
   - 領域Z: **時間**。長く開いたまま・何度も訪れた場合に世界が少しずつ変わる案（既存の hour/mood/殻と重複しない新規性）。デモでは URL や dataset で時間を進めて確認できること。
   却下済みで再提案しない: 潮の門、ファラデーの面、払う（Sweep）。
## やらないこと
上記1の変更以外の app/ 変更、UI追加、新機能の実装、見た目の調整、保存形式の変更。
## 見た目・UX の要求
desktop・mobile home は現状（静かで石が主役）と同一。殻再生は静かで、ホームとの落差が小さいこと。
## デモモード
`/?demo=1&seed=1&hour=13&shells=5` で殻をクリックして shellPlay を確認。

- 修正1は小さく。NOTES.md は4KB台、REPORT は事実のみ。
