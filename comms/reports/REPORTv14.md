# REPORT v14  (mode: normal)
## やったこと
1. shots.json 修正 — 完了
   - `stone-shadow`: 石の位置から計算した座標（石の縁の左 0.07×幅 の位置）へ `eval` で pointerdown/up を送り、450ms で撮影。`stone-shadow2` を追加（同じ操作で 900ms）。
     固定座標 clickAt を使わなかった理由: 波の速さは CSS px で見ると desktop ≈200px/s、mobile ≈60px/s と大きく違い、1 つの固定座標では両幅で「石の縁に輪が届く瞬間」が撮れないため。
   - `hold`: 先に `wait 6200` → `waitFor holding=1` → `wait 2200`。
   - `idle`: `wait 9500` → `waitFor body[data-stone-laps='2']` → `wait 160`（さざ波が立った直後を撮る）。
   - probe では desktop/mobile とも `stone-shadow` 相当で輪が石の縁に当たり欠けるのを確認。公式ハーネスでの `warnings` 空は未確認（このターンでは走らせていない）。
2. 石の質感 — 完了（wave-gl.js のフラグメントのみ、uniform `uStoneC` を 1 つ追加。新規パス/テクスチャなし）
   - 内部: 上が少し明るく下が暗い縦グラデ、水際より下を沈ませる、ごく淡い斑、左上寄りの淡い艶。
   - 縁: 左上に細い明るい弧、右下はほぼ無し。縁の外側に細い暗い溝（メニスカス）と背景のゆがみ（約 6〜10px）。波が当たった側の光は維持。
   - 塗り円盤・濃い輪郭・落ち影は使っていない。
3. 石のさざ波 — 完了
   - 起動 2 秒後に 1 回、その後は 2 回目だけ 8〜11 秒、以降 8〜14 秒ごと。縁の外側 18 点に小さな波源（振幅 0.1、通常タップの約 1/4〜1/5）。無音、`stoneHits` は増やさない。
   - 触っている最中・長押し中・石掴み中・タップ後 3.5 秒以内・タブ非表示・WebGL2 以外は出さない（3 秒後に再試行）。`dataset.stoneLaps`（`data-stone-laps`）を追加。`?demo=1` では出さない（幽霊が石を扱うため）。
   - 既存の `ripple()`/`wake(2600)` を使うだけなので常時 rAF は無く、波が止まれば既存の静止判定で止まる。

## 既知の問題・妥協点
- 石内部はまだ暗め（小石として読める程度の明暗差）。明るくしすぎると「泡」に戻るため控えめにした。
- さざ波は mobile で縁に反射が重なり、desktop より輪が目立つ。「気づく人だけ」には少し強めかもしれない（振幅 0.1）。
- さざ波と合成ポインタ（evalで送る）に依存した撮影なので、ハーネス側の eval 動作が変わると `stone-shadow` が撮れない。
- 公式ハーネスでの再撮影は未確認。
