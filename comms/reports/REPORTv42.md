# REPORT v42  (mode: normal)
## やったこと
1. 直線の筋: 完了。正体は砂のクラドニ式の対角節（f が x↔y 反対称のため X=Y が常に節になり、45° の直線が画面を貫く）。夜光虫・#aura・残像を個別に隠して切り分け、砂の線と判明。`wave-gl.js` の砂ブロックで座標を対角に沿って歪め、S 字の曲線にした。最初に試した低周波 warp は平行移動だけで直線が残り失敗（NOTES に記録）。
2. 残像強化: 完了。ムード色を白側へ 20%、光の半径 0.2+0.12v → 0.18+0.10v（半径は広げすぎると灰色の霧になり石が沈むため中間）、中心 alpha 1.0、opacity は 0.22 のまま。
3. shots.json: 変更なし。
## ORDER からの逸脱
なし。残像は「光の半径を上げる」より「明度を上げる」寄りになった（半径を広げるとかえって汚れに見えたため）。

build 成功。probe（seed=1）で desktop・mobile のタップ後 2.8s に端から端までの直線なし、consoleErrors 空。desktop は shown と残像を隠した none を比較し、差が分かり石・ヒント・バー・響は可読。mobile shown/washed も確認。

## 既知の問題・妥協点
- 砂の図形全体が少し歪む（古典的な正確さより自然さ優先）。他の図形でも対角以外の節が曲がる。
- 保存なしの home はシェーダー上は変わらない（砂は uChl.z>0 のときのみ）が、砂の線の位置は微妙に変わる。
- 残像は強めたが、依然として「淡い光」止まり。
