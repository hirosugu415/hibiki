# REPORT v91  (mode: normal)
## やったこと
1. mobile 中央の染み: 完了。原因は金の屈折方向を決める最近打点の選択が、非活性の打点 B（既定 = 画面中央）を選んでいたこと。活性な打点のうち輪の半径に近い方を使うよう修正。さらに輪の半径（uFlA/B.z）に対する帯ゲート（半径比 0.72〜1.3）で、輪以外の金を出さない。mobile-caustic-ring で金は輪に沿った帯のみ（目視）。
2. 灰色層: 一部。灰色の正体は「外側の青い帯の上に金を足した」混色だった。乗算 tint を強め（0.9→min(1,1.35ce)）、帯ゲートで青帯と金の境を整理 → desktop で 青輪→金帯 の2層、灰色層は目視で消えた。**金は青輪の内側ではなく外側のまま（未達）**。屈折オフセットを増やしても位置が動かず原因を特定できなかった。
3. desktop 昼の彩度: 完了。desktop max 0.5→0.62。
4. 維持: dataset.caustic / ?caustic=0 / ?caustick / ?causw、shots.json は変更なし（既存の caustic-ring/off/night のまま）。env=0 で分岐に入らない。
