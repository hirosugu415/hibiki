# FEEDBACK v61
## VISION 適合（絶対のルールを守れているか）
守れている。desktop-home / mobile-home は「触れてみてください」の一言と下部ガラスのツールバーだけで静かに整い、c60 から不変。ヘルス OK、コンソールエラー 0。通常タップの 3 秒体験も変化なし。

## 採点の根拠
- 良い点: desktop-press-rebound に、離した後の 2 つ目の柔らかい輪（外側の淡い輪＋内側の小さな輪）が見える。軽く上品で、白飛び・ジャギーなし。REPORT の「通常タップは rebound 0」「泉移管」の設計も妥当。
- 悪い点: ORDER の核だった「指の下の凹みの陰影」は、desktop-press-hold・mobile-press-hold のどちらでも判別できない。指の位置にあるのは小さな明るい輪（タップ輪）で、凹みではない。mobile は指が隠す分さらに見えない。REPORT 自身も「静止画で分かる程度」と認めており、実際はそれ未満。触り心地の差は値（dataset）でしか証明できず、UX としては体感されにくい。
- 点数は据え置き（7）。上げる新しい視覚証拠が無い。ただし回帰もない。

## 動作確認で分かったこと
- probe で drag 短距離＋150ms を撮ったが、drag は離した後の状態になり押下中の深さは 0（touch="1614,0.0000,0"）。押下中の凹みは自分では静止画で確認できず、shots の press-hold も凹みの証拠にならなかった。
- touchPos は「凹みx,y,指x,y」を出しており、追従バネの値は dataset で追える。

## 方向性の判断
polish。方向は良いが、感じられない凹みは存在しないのと同じ。強さと半径を、染みにならない範囲で「見える」ところまで引き上げ、検証手段（拡大クロップ）を作る。

## 次に最も効くこと
1. 凹みを知覚できる強さへ（半径を短辺比 0.08 前後、強さ約 2〜3 倍）。勾配のみ・縁なし・発光なし。
2. mobile で指の周囲に陰影が出る大きさにする。
3. press-hold の撮影を押下中・泉開始前に確実に撮り、凹み単体の拡大 PNG を shots に追加。
