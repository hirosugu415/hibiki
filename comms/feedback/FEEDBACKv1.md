# FEEDBACK v1

## VISION 適合（絶対のルールを守れているか）
**概ね適合（ただし「Apple 水準」には未達）。**
- 3秒ルール: `?demo=1` の `desktop-home.png` は初回から波紋が複数見え、空っぽではない。通常モードの `probe/mobile-normal-fresh.png` も、起動直後に1つ大きな波紋と「触れてみてください」があり、何をすべきか分かる。タップ 150ms 後（`probe/desktop-tap-150ms.png`）には、触れた位置（640,300）から明るい輪が出ており、即応している。
- クローム: ガラスバー・SVG アイコン・「響」は統一されている。実測でボタンは 76×48 と 48×48 で、44px 以上。390px 幅でも端に触れていない（`mobile-home.png`）。
- 違反寄りの点: 画面が「水面」ではなく「細い輪の絡まった針金」に見える。`desktop-home.png`、`desktop-touched.png`、`probe/desktop-drag.png` が該当する。洗練・余白・静けさの面でまだ Apple 水準ではない。

## 採点の根拠
良い点
- ヘルス OK。ビルドは成功、コンソールエラーは 0、真っ白な画面は無し。
- 波の新鮮な輪は美しい。`desktop-tap-150ms.png` は屈折とリム光があり、ジャギーも無い。
- バーは凪／夜の切替が約1秒でクロスフェードし、選択インジケータもなめらか。
- 音状態は probe で idle → running → muted と遷移した。Web Audio と dataset が機能している。

悪い点
- **波が減衰しなさ過ぎる。** `desktop-home.png` や `desktop-touched.png` は、画面全体が重なった細い輪で埋まっている。ドラッグ後（`probe/desktop-drag.png`）は髪の毛のような線の網目になり、「凪」の瞑想感がなく、ノイジーで汚い。
- 波の線が細く、全体にコントラストが低い。主役である新鮮な一撃と、古い残響が同じ重みで見え、階層がない。
- **暁ムードが「暁」ではない。** `probe/mobile-dawn.png` は暗いワイン色で、ORDER の「琥珀〜桃・明るめ」と食い違う。波紋はほぼ判別できず、のっぺりしている。
- ヒント「触れてみてください」は透明度が低く、青背景では読みにくい。
- 音と光が結びついていない。どの音の高さを鳴らしたかが画面に出ず、VISION の「波・音・光が1つの面で結びつく」が弱い。
- REPORT は「煌めきは伸びしろ」と自己申告しており、実際その通り。一方、「ムード別に水面の表情が変わる」とは言えない（色が変わるだけ）。

## 動作確認で分かったこと
- probe（デスクトップ・スマホ両方）で通常モードを開き、中央をクリック、ドラッグ、ミュート、暁へ切替の順に操作した。コンソールエラーは無し。ボタンの実寸は 76×48 ×3 と 48×48。
- 波の減衰が弱いため、数回タップするだけで画面が線で埋まる。
- 暁に切り替えた直後の画面は、波がほぼ見えない。

## 方向性の判断
**polish。** 土台（物理・音・クローム）は成立しているので、方向転換の必要はない。伸びしろは「静けさ・階層・光の質」の調整にある。次は、波を減衰させて画面を水面らしく静め、触れた瞬間を主役に見せ、音の高さを光で可視化する。

## 次に最も効くこと
1. 減衰を強めて静けさを作り、古い波は淡く、新しい波は明るく太くする。ドラッグは線の網目にならないようにする。
2. 暁を琥珀〜桃の明るいパレットにし直し、3ムードで波の質感も変える（光り方・屈折の強さ）。
3. タッチ時の光（フラッシュ）と、音高に応じた色相のわずかな変化を入れる。ヒントの視認性も上げる。
